# 🔤 英语 · 启蒙乐园

> 3–6 岁 · 学科概况

这个阶段只做一件事：让耳朵习惯另一种声音。
不背单词、不讲语法，先建立「这门语言听起来很亲切」的感觉。

## 重点内容

- **磨耳朵**：每天固定播放英文儿歌或绘本音频，不求听懂。
- **听懂指令**：Stand up、Sit down、Give me…，用动作配合理解。
- **字母认读**：认识 26 个字母的形状和名字，为自然拼读做准备。

## 学习建议

- 一次只输入一点点，重复十遍胜过换十个新内容。
- 家长跟着一起说、一起做动作，孩子才会觉得安全。
- 不要考问「这个单词什么意思」，先让声音和场景绑定。
