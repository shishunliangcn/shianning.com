# 📖 语文 · 启蒙乐园

> 3–6 岁 · 学科概况

认字从「看得见、摸得着」的东西开始：门、窗、碗、鞋、爸爸妈妈的名字。
这个阶段的目标不是识字量，而是让孩子发现「这些符号和我有关」。

## 重点内容

- **生活识字**：在家具、包装、路牌上认字，比字卡更容易记住。
- **绘本共读**：每天一本，读的时候用手指着字，让声音和字形对上。
- **完整表达**：鼓励孩子把一件事说完整——「谁、在哪里、做了什么」。

## 学习建议

- 每天 10 分钟，宁可短而固定，不要一次学半小时然后停一周。
- 孩子问「这是什么字」时立刻回答，这是最好的教学时机。
- 不要纠正每个发音，先保护开口的意愿，再慢慢正音。
