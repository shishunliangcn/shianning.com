# 🔍 自然与科学 · 启蒙乐园

> 3–6 岁 · 学科概况

科学启蒙不是背知识，是保留「为什么」。
这个阶段把数学也装进来：数数、比较、分类、形状，都在生活里完成。

## 重点内容

- **观察与提问**：蚂蚁怎么搬家、叶子为什么变黄、水到哪里去了。
- **生活中的数学**：数到 20、比多少、按颜色和大小分类、认识基本图形。
- **天气与季节**：记录晴天雨天，感受冷热变化与穿衣的关系。
- **简单因果**：种一颗种子、养一盆植物，看它慢慢长起来。

## 学习建议

- 每周安排一次户外观察，带放大镜和一个小本子。
- 孩子问「为什么」时，先反问「你觉得呢」，再一起找答案。
- 数东西时让孩子用手点，一个一个对应，这是数感的根。
