# 🤝 社会与品格 · 启蒙乐园

> 3–6 岁 · 学科概况

品格不是讲道理讲出来的，是在一次次相处里练出来的。
这个阶段的核心是：认识情绪、学会等待、知道边界。

## 重点内容

- **情绪认知**：能说出「我生气」「我难过」，而不只是哭闹。
- **规则与等待**：排队、轮流、用完归位，理解规则是为了大家。
- **分享与合作**：从「我的」到「我们一起」，在游戏中练习协商。
- **礼貌与边界**：会说请、谢谢、对不起，也知道自己的身体别人不能随便碰。

## 学习建议

- 先命名情绪，再讲道理：「你很生气，因为积木倒了。」
- 用绘本和角色扮演演练社交场景，比事后说教有效。
- 家长示范比要求更有用——你怎么对人，孩子就怎么对人。
