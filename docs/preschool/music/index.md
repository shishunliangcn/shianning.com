# 🎵 音乐 · 启蒙乐园

> 3–6 岁 · 学科概况

音乐启蒙从身体开始：先能跟着节拍动，再谈唱得准不准。
这个阶段的成果是「敢唱、爱听、能分辨」。

## 重点内容

- **节奏感**：拍手、跺脚、走步，跟着稳定拍子做动作。
- **身体律动**：快慢、强弱、高低，用身体感受音乐的变化。
- **听辨**：分辨高音与低音、长音与短音、响亮与轻柔。

## 学习建议

- 用熟悉的儿歌打拍子，比专门练节奏更容易坚持。
- 家里准备几件简单打击乐（沙锤、三角铁、小鼓），随手就能玩。
- 唱错不要打断，先唱完整，再一起纠正一两处。
