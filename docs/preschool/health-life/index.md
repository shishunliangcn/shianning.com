# 🌱 健康与生活 · 启蒙乐园

> 3–6 岁 · 学科概况

这个阶段最重要的一门「学科」，其实是照顾自己。
会穿衣、会洗手、能好好吃饭睡觉的孩子，进入集体生活时明显更从容。

## 重点内容

- **生活自理**：穿脱衣服、系扣子、独立如厕、饭前洗手。
- **饮食与作息**：认识常见食物，固定睡觉与起床时间。
- **安全常识**：不跟陌生人走、热水和插座要远离、走散时找谁求助。
- **身体认知**：认识五官与身体部位，能说出「哪里不舒服」。

## 学习建议

- 让孩子自己来，允许他慢——包办会让孩子失去练习的机会。
- 把步骤编成儿歌或顺口溜，比反复催促有效。
- 作息比营养补充剂更重要，固定的睡前流程能省下很多拉扯。
