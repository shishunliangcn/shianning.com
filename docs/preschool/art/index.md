# 🎨 艺术与创想 · 启蒙乐园

> 3–6 岁 · 学科概况

这个阶段的「作品」好不好看不重要，重要的是敢不敢动手。
涂鸦、手工、唱游，都是孩子表达情绪的语言。

## 重点内容

- **涂鸦与绘画**：从乱涂到有意识地画圆、画人，认识颜色。
- **手工与黏土**：撕纸、粘贴、揉捏，锻炼手部小肌肉。
- **唱游与律动**：跟着音乐拍手、走步、做动作，感受快慢强弱。
- **欣赏**：看画、听曲，能说出「我喜欢哪里」。

## 学习建议

- 材料比技巧重要：纸、笔、黏土、废旧纸盒，随时能取用。
- 不要评价「像不像」，问「你画的是什么故事」。
- 把作品贴起来或拍照留存，孩子会为自己的创作骄傲。
