# 🗣️ 语言与表达 · 启蒙乐园

> 3–6 岁 · 学科概况

语言不是从识字开始的，是从「有人愿意听我说」开始的。
这个阶段的成果是：敢开口、说得完整、听得懂故事。

## 重点内容

- **亲子共读**：每天一本绘本，用手指着字读，让声音和字形对上。
- **完整表达**：引导孩子说清「谁、在哪里、做了什么、后来怎样」。
- **儿歌与韵律**：押韵的句子最容易记住，也最容易模仿发音。
- **前书写准备**：涂鸦、描线、捏橡皮泥，先把小手的力量练出来。

## 学习建议

- 多问开放式问题：「你觉得他为什么哭了？」而不是「是不是哭了？」
- 孩子说话时不打断、不抢着替他说完。
- 把孩子的「金句」记下来，读给他听，他会更愿意表达。
