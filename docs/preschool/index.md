# 👶 启蒙乐园

> 3–6 岁 · 玩中学，把好奇心留在身边

这个学段最重要的不是「学会多少」，而是让孩子觉得文字、数字和声音是有趣的。
所有内容都围绕生活场景展开，一次十分钟，学完就能用上。

## 这个学段在做什么

- **建立亲近感**：先喜欢，再谈掌握。认字、数数、唱歌都以游戏的方式进行。
- **保护注意力**：单次学习控制在 10–15 分钟，宁可短而常，不要长而断。
- **积累生活经验**：逛超市、坐公交、做饭，都是最好的教材。

## 怎么陪着学

1. **固定时间**：每天同一时段，形成习惯比延长时长更有效。
2. **先示范再要求**：家长读一遍、数一遍，孩子自然会模仿。
3. **允许重复**：同一本绘本读十遍是正常的，重复就是学习。
