# 🔢 数学 · 启蒙乐园

> 3–6 岁 · 学科概况

数学启蒙不是提前学算术，而是建立「数量、形状、顺序」这三种感觉。
最好的教材是厨房、楼梯和超市。

## 重点内容

- **数感**：从 1 数到 20，理解「几个」而不只是背口诀。
- **图形与空间**：认识圆形、方形、三角形，说出「上面、里面、旁边」。
- **分类与排序**：按颜色、大小、用途把东西分堆，再按长短排队。

## 学习建议

- 数东西时让孩子用手点，一个一个对应，这是数感的根。
- 上下楼梯时一起数台阶，比坐着做练习册自然得多。
- 分水果、摆碗筷，都是现成的分类与一一对应练习。
