# 🧪 化学 · 中学冲刺

> 12–18 岁 · 学科概况

化学是一门「既要记、又要讲道理」的学科：
物质的性质要背，但反应为什么发生、为什么这样配平，靠的是理解。

## 重点内容

- **物质构成**：原子结构、元素周期律、化学键与晶体类型。
- **反应规律**：氧化还原、离子反应、酸碱盐、反应速率与平衡。
- **有机初步**：烃与烃的衍生物，官能团决定性质。
- **实验探究**：气体制备、物质检验、定量实验与误差分析。

## 学习建议

- 用「结构决定性质」这条主线串知识点，就不会散。
- 化学方程式要理解配平逻辑，不要只背系数。
- 实验题先看目的，再看装置，最后才看细节。
