# 📚 中学冲刺

> 12–18 岁 · 系统梳理，把难点一个个拆开

十门学科对应中高考的完整盘面。这个阶段的知识量陡增，
靠记忆已经不够：必须建立体系，学会把题目拆成可处理的步骤。

## 这个学段在做什么

- **建体系**：先有框架再填细节，零散的知识点记不住也用不上。
- **拆难点**：把压轴题拆成若干个基础动作，逐个练熟再合起来。
- **错题归因**：错题本不是抄题，而是写清「错在哪一步、为什么错」。

## 怎么陪着学

1. **按专题推进**：一个专题吃透再下一个，比平行铺开更稳。
2. **限时训练**：平时就要有计时习惯，考场上的节奏是练出来的。
3. **定期回看**：每周抽二十分钟翻错题，比做新题更能提分。
