# 🌏 地理 · 中学冲刺

> 12–18 岁 · 学科概况

地理是「理科的思维 + 文科的表达」：
自然地理讲原理，人文地理讲分析，最后都落到读图与表达上。

## 重点内容

- **自然地理**：地球运动、大气环流、水循环、地貌与板块。
- **人文地理**：人口、城市、农业、工业与区位选择。
- **区域地理**：中国分区、世界主要区域的特征与差异。
- **图表能力**：等值线图、统计图、区域图的判读。

## 学习建议

- 每天看一次天气图或地图，地图感是练出来的。
- 大题按「自然 + 人文 + 社会经济」几个维度分点作答。
- 原理图要能自己画出来，画得出来才算真懂。
