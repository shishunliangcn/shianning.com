# 📜 历史 · 中学冲刺

> 12–18 岁 · 学科概况

历史不是背年份，而是在时间轴上解释「为什么事情会这样发生」。
中学阶段的重点是两条主线：中国史和世界史，以及它们如何交汇。

## 重点内容

- **中国古代史**：朝代更替、制度演变、经济与文化。
- **中国近现代史**：从鸦片战争到改革开放的主线。
- **世界史**：古代文明、近代革命、两次世界大战与冷战。
- **史料阅读**：区分一手史料与后世评述，学会提取信息。

## 学习建议

- 先背「大框架时间轴」，再往里填细节，不要一上来就记年份。
- 每学一个事件，问三句：背景是什么、做了什么、影响是什么。
- 材料题答案尽量用材料里的词，再结合所学。
