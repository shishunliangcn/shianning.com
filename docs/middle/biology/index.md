# 🧬 生物 · 中学冲刺

> 12–18 岁 · 学科概况

生物学的核心是「层次」：分子 → 细胞 → 组织 → 器官 → 个体 → 种群 → 生态系统。
把概念放进层次里，就不会记混。

## 重点内容

- **细胞与代谢**：细胞结构、光合与呼吸、酶与能量。
- **遗传与进化**：孟德尔定律、基因表达、自然选择。
- **稳态与调节**：神经调节、体液调节、免疫。
- **生态与环境**：种群、群落、生态系统与人类活动的影响。

## 学习建议

- 画图记忆：细胞结构图、遗传系谱图、能量流动图。
- 实验设计题抓住「单一变量」和「对照」两个词。
- 用生活现象反推原理，比如为什么运动后会喘。
