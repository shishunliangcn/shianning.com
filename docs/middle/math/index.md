# 🔢 数学 · 中学冲刺

> 12–18 岁 · 学科概况

中学数学是「代数」和「几何」两条腿走路：
代数讲关系与变化，几何讲结构与证明，最后在函数与解析几何里合流。

## 重点内容

- **代数主线**：方程、不等式、函数（一次到二次再到指对），理解图像与式子的对应。
- **几何主线**：三角形全等相似、圆的性质、辅助线的常见作法。
- **统计与概率**：读懂图表，算清均值方差，理解随机事件的独立性。
- **压轴题策略**：先把能拿的分拿到，再按「设参数—列关系—解—检验」推进。

## 学习建议

- 公式要会推，不能只背；推一遍就忘不掉了。
- 每道错题写清「卡在哪一步」，比抄十遍原题有效。
- 平时限时做题，考场才不会因为节奏乱而丢分。
