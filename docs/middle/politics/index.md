# ⚖️ 政治 · 中学冲刺

> 12–18 岁 · 学科概况

政治的难点不在背，而在「用规范的语言说清道理」。
知识是骨架，材料是血肉，答题是把两者接起来。

## 重点内容

- **道德与法治**：权利义务、法律常识、社会责任。
- **经济生活**：价格、消费、生产、分配与市场经济。
- **政治生活**：国家制度、公民参与、国际关系。
- **哲学与文化**：唯物辩证法、认识论、文化传承与创新。

## 学习建议

- 每个知识点整理成「原理 + 方法论 + 应用场景」三段式。
- 答题先定范围（经济/政治/哲学），再套原理，最后结合材料。
- 关注时事，但只记与考点相关的部分。
