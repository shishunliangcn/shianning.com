# 🏃 体育与健康 · 中学冲刺

> 12–18 岁 · 学科概况

中学的体育有两张考卷：一张是体测，一张是三年后的身体。
前者靠训练，后者靠习惯，两者不冲突。

## 重点内容

- **中考体测项目**：长跑、立定跳远、引体向上/仰卧起坐、球类选考。
- **体能训练**：心肺耐力、力量、柔韧与协调。
- **运动损伤预防**：热身、拉伸、护具与常见伤处理。
- **健康管理**：睡眠、用眼、饮食与情绪调节。

## 学习建议

- 长跑靠「配速」而不是「冲刺」，平时就要练匀速。
- 力量项目按周计划渐进加量，别一次练到酸痛一周。
- 睡眠不足会直接拖垮记忆和情绪，比多刷一套题重要。
