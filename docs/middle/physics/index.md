# ⚛️ 物理 · 中学冲刺

> 12–18 岁 · 学科概况

物理的难，一半难在概念，一半难在建模。
先想清楚「这个现象里谁在动、受了什么力」，再列式子，比背公式有效得多。

## 重点内容

- **力学**：受力分析、牛顿定律、功与能、动量守恒。
- **电学**：电路分析、欧姆定律、电功率、电磁感应。
- **光学与热学**：反射折射、透镜成像、内能与比热。
- **实验与误差**：测量工具的使用、数据分析、误差来源。

## 学习建议

- 每道题先画图：受力图、电路图、光路图，图对了题就成了一半。
- 单位要跟着一起算，量纲不对说明思路错了。
- 错题写清「哪个模型建错了」，比抄答案有用。
