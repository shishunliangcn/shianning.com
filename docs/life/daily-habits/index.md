# 🧼 日常习惯

> 长生馆 · 生活、生存与实用技能

习惯不是靠提醒，是靠流程。
把「快去洗手」变成「进门先洗手」，靠的不是嗓门，而是固定顺序和可见的提示。

## 从这里开始

- [洗手七步法（宝宝版）](/life/daily-habits/baby-wash-hands) —— 用七个表情记住七步

## 会聊到的问题

- 洗手、刷牙、穿衣、收拾，怎么教才不费劲？
- 提醒越少，习惯越好，这可能吗？
- 要不要用奖励？奖励会不会适得其反？
- 大人自己也做不到，怎么办？

## 学习方式

- **流程化**：固定顺序、固定位置、固定时间。
- **可视化**：把步骤贴在孩子看得见的地方。
- **一起做**：示范永远比要求有效。
