# 🛡️ 自我保护

> 长生馆 · 生活、生存与实用技能

有些知识希望一辈子用不上，但必须提前装进脑子里。
自我保护的核心不是「别去危险的地方」，而是「遇到危险时知道做什么」。

## 会聊到的问题

- 在商场走散了，应该站在原地还是找人？
- 被同学欺负了，先告诉谁？
- 有人让我「保守秘密」，但那个秘密让我不舒服，怎么办？
- 家里哪些地方容易触电？湿手能碰开关吗？
- 陌生人说「你妈妈让我来接你」，怎么判断？

## 三条底线

1. **大声说出来**：害怕的时候，喊叫是最有效的武器。
2. **先离开，再讲理**：人身安全永远高于「礼貌」。
3. **一定要告诉一个大人**：被欺负不是你的错，隐瞒才会让事情更糟。

## 给家长

与其教孩子「不要和陌生人说话」，不如教他分辨「什么样的接触是可疑的」，
并明确告诉他：无论发生什么，你都不会先责怪他。
