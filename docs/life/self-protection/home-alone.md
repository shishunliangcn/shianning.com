# 独自在家，有人敲门

🚪 门铃响了。

家里只有你一个人。

## 先记住一条

**无论外面是谁，都不要开门。**

不是「看看是谁再决定」，是**根本不开**。

## 可以做的事

1. **不出声**，先听。
2. 如果是熟人（比如邻居阿姨），**隔着门说话**：
   > 「我妈妈现在不方便，您晚点再来吧。」
3. **不要说「我一个人在家」。**
   可以说「我爸妈在忙」「他们在休息」。
4. 如果对方一直不走，或者反复敲门：**打电话给爸妈**，必要时打 110。

## 几种常见说法

- **「我是修水管的。」** → 「我爸妈没预约，您改天再来。」
- **「你妈妈让我来拿东西。」** → 「我打给我妈确认一下。」（然后真的打）
- **「我是你爸的朋友。」** → 「我叫我爸来跟您说。」（然后不开门）

**核心是：任何要求，都推给「我爸妈」。**

## 快递和外卖

- 让放在门口，等人走了再拿。
- 不要开门接。

## 家长要做的

- 出门前说清楚：**「任何人来都不开门，包括你认识的人。」**
- 留一个能随时打通的电话。
- 和孩子演练一次——真的敲一次门，看他怎么反应。

**演练过的孩子，遇到时反应快得多。**
