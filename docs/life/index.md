# 🛠️ 长生馆

> 生活、生存与实用技能

“长生”不是修仙，是好好活着。
这座展馆讲的是最要紧、却最没人系统教的东西：怎么自救，怎么持家，怎么不被骗。

## 怎么逛这座馆

1. **先记动作，再记原理**：紧急时刻没时间推理。
2. **在真实场景里练**：厨房、浴室、银行柜台，都是课堂。
3. **定期复习**：急救知识会忘，半年过一遍。
