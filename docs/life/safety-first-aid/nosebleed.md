# 流鼻血，别仰头

🩸 鼻子出血了。

大人说：「快仰头！」

**这是错的。**

## 为什么仰头不对

血不会「回去」，它只是**流进了咽喉**。

结果：

- 血被咽进胃里，可能引起恶心、呕吐
- 呛进气管，可能窒息
- 你不知道到底流了多少血

**仰头只是「看不见」，不是「止住了」。**

## 正确的四步

1. **坐下，身体向前倾**（不是后仰）
2. **用嘴呼吸**
3. **用手指捏住鼻翼**（鼻子下半部分的软处），持续 **10 分钟**
4. 中间**不要松手看**——松了就要重新计时

**10 分钟后大部分鼻血会停。**

## 可以加一件

**在前额或鼻梁上敷冷毛巾**，帮助血管收缩。

（但别躺下，别后仰。）

## 什么时候该去医院

- 按压 20 分钟 still 不止
- 出血量很大，或伴随头晕、心慌
- 是头部被撞之后开始出血
- 频繁流鼻血（一周好几次）

## 平时怎么预防

- 别抠鼻子
- 干燥的季节用加湿器
- 鼻腔太干可以涂一点凡士林（少量）
