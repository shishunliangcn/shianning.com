# 🚑 安全急救

> 长生馆 · 生活、生存与实用技能

急救知识的特点：平时用不上，用上时决定生死。
这门主题只讲「第一时间该做什么」，不讲用不上的理论。

## 从这里开始

- [烫伤后的第一件事是什么](/life/safety-first-aid/burns) —— 大多数人第一反应就是错的

## 会覆盖什么

- 烫伤、割伤、鼻出血
- 气道异物梗阻（海姆立克）
- 心肺复苏与 AED
- 中暑、溺水、触电

## 学习方式

- **记动作，不背原理**：紧急时刻没有时间推理。
- **半年复习一次**：急救知识遗忘得很快。
- **真的练一次**：按压深度和频率，光看视频是学不会的。
