# 烫伤后的第一件事是什么

被热水烫到的那一刻，大多数人的第一反应是：找牙膏、抹酱油、拿冰块敷。

这三个动作都不对，而且会加重损伤。

## 正确答案：立刻用流动的冷水冲

**15 到 20 分钟**，水温大约 15–25 ℃，让水流温和地冲过伤处。

不要用冰水，不要用冰块——低温会造成二次冻伤，让已经受损的皮肤雪上加霜。

## 为什么是「冲」而不是「涂」

烫伤的本质是**热量还在往皮肤深层传导**。
冲冷水的目的不是「消毒」，而是**把残余热量带走**，阻止损伤继续向深处蔓延。

任何涂在表面的东西都会形成一层膜：
- 阻碍散热；
- 让医生难以判断伤情；
- 增加清创时的疼痛和感染风险。

> 记住一句话：**先降温，再处理，最后才考虑用药。**

## 五字口诀：冲、脱、泡、盖、送

| 步骤 | 做什么 | 注意 |
| --- | --- | --- |
| **冲** | 流动冷水冲 15–20 分钟 | 水不要直接冲击伤口中心 |
| **脱** | 小心脱去或剪开衣物 | 粘在伤口上的布**不要硬撕** |
| **泡** | 疼痛明显时可再泡冷水 10–30 分钟 | 大面积烫伤、老人小孩不宜久泡 |
| **盖** | 用干净纱布或棉布覆盖 | 不要用有毛絮的材料 |
| **送** | 严重时立即就医 | 大面积、面部、关节、会阴部优先 |

## 绝对不要做的事

::: danger 这些偏方有害
- **涂牙膏、酱油、香油、面粉**：污染伤口，妨碍散热和判断
- **直接敷冰块**：造成冻伤，血管收缩反而加重组织坏死
- **挑破水泡**：水泡皮是最好的天然敷料，破了容易感染
- **用力撕粘住的衣物**：会把皮肤一起撕下来
:::

## 什么时候必须去医院

- 烫伤面积大于伤者**一个手掌**；
- 出现**大水泡**，或皮肤发白、发黑、失去痛觉；
- 部位在**面部、手、足、关节、会阴**；
- 由**电、化学品**造成的烧伤；
- 伤者是**婴幼儿、老人、孕妇**，或本身有慢性病。

## 一个容易忽略的细节

降温之后不要立刻涂抹任何药膏，让医生看原始伤情。
如果实在疼痛难忍，可以用干净湿纱布持续冷敷，直到就医。

::: tip 把它变成家庭常识
把「冲 15 分钟」这几个字写在厨房和浴室能看见的地方。
紧急时刻，人是想不起搜索的。
:::
