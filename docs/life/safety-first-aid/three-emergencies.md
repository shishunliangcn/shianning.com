# 触电、溺水、中暑：三个救命动作

⚡ 这三件事有个共同点：**做错第一步，后面全错。**

## 一、触电

**第一件事永远是：断电。**

不是拉人，不是喊人，是切断电源。

- 拔插头、关总闸。
- 如果够不到，用**干燥的木棍、塑料椅、厚书**把电线或人挑开。
- **绝对不要用手直接拉**——你也会被电住。

断电之后：

- 检查呼吸和意识。
- 没有呼吸 → 立刻心肺复苏 + 打 120。
- 有呼吸 → 让他平躺、保暖，等急救车。

**烧伤的地方用流动冷水冲 15–20 分钟**，不要涂牙膏、酱油、香油。

## 二、溺水

**第一原则：不要贸然下水。**

每年都有救人的人自己溺水。正确的顺序是：

1. **大声呼救**，让人打 120。
2. **抛**：救生圈、空塑料桶、绳子、长杆——任何能让他抓住的东西。
3. **如果他离岸很近**，趴下来（降低重心）用杆子拉，不要站着伸手。

救上岸之后：

- 没有呼吸 → **立刻心肺复苏**，不要先「控水」（控水会耽误时间）。
- 有呼吸 → 侧躺、保暖，送医院（溺水后几小时仍可能恶化）。

## 三、中暑

先分清两种：

**热衰竭（较轻）**：头晕、恶心、大量出汗、皮肤湿冷。

- 移到阴凉处
- 解开衣物
- 用凉水擦身、扇风
- 清醒的话，少量多次喝淡盐水

**热射病（危险）**：**皮肤干热、不出汗、意识模糊、体温很高。**

- 立刻打 120
- 一边等一边降温：冷水浇身、冰袋放在脖子/腋下/大腿根
- **不要给他喝水**（意识不清会呛）

## 一个通用顺序

记住这四个字的顺序，三件事都适用：

> **先保自己 → 再呼救 → 再施救 → 最后送医。**

**先保自己**不是自私。救不了自己，就救不了别人。
