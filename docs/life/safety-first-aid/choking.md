# 噎住了：那三分钟能救命

⚠️ 一个人突然不说话、脸色发紫、双手抓住自己的喉咙。

他知道自己噎住了，但**说不出话**。

这种情况，从发生到危险，通常只有几分钟。

## 第一步：判断是「能咳」还是「不能咳」

**能咳嗽、能出声**：气道没有完全堵住。

→ **鼓励他用力咳**。不要拍背（可能让异物掉得更深），不要用手指乱掏。

**不能咳嗽、不能说话、不能呼吸**：完全梗阻。

→ 立刻施救，同时让人打 120。

## 第二步：海姆立克急救法（成人 / 大孩子）

1. 站到他身后，双臂环抱他的腰。
2. 一手握拳，拳眼放在**肚脐上方、胸骨下方**。
3. 另一只手包住这个拳头。
4. **快速向内、向上冲击**。
5. 反复做到异物排出，或他失去意识。

每一次冲击都要干脆，不要犹豫。

## 如果是一岁以下的婴儿

**不能用腹部冲击**（会伤到内脏）。

正确做法是**背部拍击 + 胸部按压**：

1. 让婴儿趴在你的前臂上，头低脚高，托住下巴。
2. 用手掌根部拍背 **5 次**。
3. 翻过来，用两根手指按压胸部中央 **5 次**。
4. 交替进行，直到异物出来。

## 如果只有你一个人

1. 找一个椅背、桌角或栏杆。
2. 把上腹部顶在上面。
3. 身体向下、向内用力压。

## 他失去意识了怎么办

1. 让他平躺，**立刻打 120**。
2. 开始心肺复苏（胸外按压）。
3. 每次按压前，快速看一眼嘴里有没有异物——**只有看得见才取，看不见不要乱掏**。

## 三件不要做的事

- **不要用手指盲目掏**：可能把异物推得更深。
- **不要给他喝水**：水会让情况更糟。
- **不要在能咳嗽时拍背**：可能让异物移位、卡得更死。

## 预防比急救简单

- 三岁以下：**整颗坚果、果冻、葡萄、汤圆**都要切小或避免。
- 吃东西时不跑、不笑、不躺着。
- 小孩吃东西时，大人要在视线范围内。
