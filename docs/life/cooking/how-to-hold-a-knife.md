# 切菜的手

🔪 第一次拿刀，大多数人的问题是：**手不知道放哪儿。**

于是手指伸直按着菜，刀一下去，指头就在刀刃下面。

## 左手：猫爪

按菜的那只手，手指要**向内扣**，用指关节顶住刀面。

```
指尖缩回去，指关节朝外——
刀贴着指关节上下，指尖永远在安全区。
```

这叫「猫爪手」。看起来别扭，练两次就习惯了。

**切得慢，是安全的。切得快，才会出事。**

## 右手：刀尖不离砧板

不要整把刀抬起来剁。

正确的动作是：**刀尖始终贴着砧板，刀跟抬起来，像铡刀一样往下切。**

这样省力，也更容易控制。

## 三个新手最容易犯的错

1. **手指伸直按菜** → 用猫爪手。
2. **刀举得太高** → 刀尖不离板。
3. **菜在板上滑** → 切之前把底部切平，让它站稳。

## 刀钝比刀快更危险

钝刀会打滑，打滑就切到手。

**刀要常磨。** 快的刀切下去是「进去」，钝的刀是「滑开」。

## 拿刀走路

- 刀刃朝下、朝后
- 刀口贴着自己的腿侧
- 递刀给别人：**握住刀背，把刀柄递出去**，或者说「我放桌上，你自己拿」
