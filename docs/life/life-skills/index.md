# 🧰 生活常识

> 长生馆 · 生活、生存与实用技能

这类知识没人系统教，但每天都要用：
怎么挑房子、怎么签合同、家电坏了先查什么、证件丢了怎么补，
以及怎么让洗手刷牙变成不用提醒的习惯。

## 从这里开始

- [洗手七步法（宝宝版）](/life/life-skills/baby-wash-hands) —— 用七个表情记住七步

## 会聊到的问题

- 租房合同里哪些条款最容易吃亏？
- 家里跳闸了，第一步做什么？
- 快递丢了、商家不退款，怎么维权？
- 收纳的本质是什么？

## 学习方式

- **建一个「办事清单」**：办过的事记下流程，下次省一半时间。
- **保留凭证**：合同、发票、聊天记录，关键时刻都是证据。
- **先查官方渠道**：网上教程鱼龙混杂，政务网站最准。
