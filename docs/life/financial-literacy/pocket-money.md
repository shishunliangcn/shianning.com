# 零花钱的三种花法

🪙 每个月，你拿到一笔自己的钱。

然后你很快花光了，买了一些现在想不起来是什么的东西。

没关系。**零花钱本来就是用来花错的。**

## 把零花钱分成三份

拿到手的第一件事，不是想买什么，而是先分：

**1. 花的（50%）**

随便花。买零食、买卡片、买你三天后就后悔的东西，都行。

**2. 存的（40%）**

攒起来，为了一个更大的东西：一辆车模、一次旅行、一台自己的设备。

**它的意义不是钱，是「等待」的练习。**

**3. 送的（10%）**

给别人：给朋友买个小礼物、捐给需要的地方。

这一份在教你一件事：**钱不只能满足自己。**

## 为什么不能全都存起来

因为那样你会讨厌存钱。

零花钱的第一目标是**练习**，不是攒钱。允许自己花错，你才知道什么值得买。

## 一个简单的判断方法

想买一个东西时，问三个问题：

1. **我会用它超过十次吗？** 会 → 值得考虑。不会 → 再等等。
2. **如果明天它降价一半，我还会想买吗？** 会 → 那是真想要。不会 → 你只是被价格打动。
3. **三天后我还记得它吗？** 记不得 → 大概率是一时冲动。

**等三天，是最好用的过滤器。**

## 记账不是给别人看的

记下来，只为一件事：**月底回头看，哪些钱花得值。**

你会发现很反直觉的一点：让你最开心的，往往不是最贵的那笔。
