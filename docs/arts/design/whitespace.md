# 留白不是浪费

⬜ 一张海报，内容挤得满满当当。

另一张，只放了一句话，四周大片空白。

**第二张反而更有力。**

## 留白在做什么

**1. 告诉眼睛先看哪儿**

空白把内容「框」起来。

四周留空的东西，会自动变成焦点。

**2. 控制节奏**

文字之间的空白，决定你读得快还是慢。

**挤在一起 = 一口气读完，容易累。**

**3. 制造质感**

奢侈品广告、高档餐厅菜单，共同点是**敢留白**。

空白在这里说的是：**我不需要塞满东西来吸引你。**

## 一个常见误解

「页面空着太浪费了，再放点东西吧。」

**这是最常见的错误。**

空白不是「还能放东西的地方」，它本身就是设计的一部分。

## 怎么用

- **段落之间**留出明显间距，让眼睛有停顿
- **重要内容**周围留更多空
- **不要贴边**：内容离边缘太近，会显得局促
- **手机上**留白更重要：屏幕小，挤一点就喘不过气

## 一个检验

把画面缩小到手机屏大小，还能看清重点吗？

**如果不能，说明留白不够——而不是内容太少。**
