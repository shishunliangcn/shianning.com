# 为看不见的人设计

♿ 一个只有颜色的按钮，色盲的人分不清。

一个只有声音的提示，听不见的人收不到。

**设计如果只考虑「标准用户」，就会把一部分人挡在门外。**

## 几个常见的「无障碍」做法

**1. 不只靠颜色传达信息**

红灯和绿灯，形状也不一样。

**「红色 = 错误」要配上文字或图标**，因为有人分不清红绿。

**2. 对比度足够**

浅灰字配白底，看着「高级」，但很多人看不清。

**文字和背景要有足够的明暗差距。**

**3. 能放大**

字号能调大而不破版，页面能用屏幕阅读器读出来。

**4. 能只用键盘操作**

不用鼠标也能走完全部流程。

## 为什么这不只是「少数人的事」

- 眼睛老花的人、在太阳底下看手机的人、手受伤的人——**每个人都会在某些时刻「不方便」**。
- 推婴儿车的人需要坡道，拎箱子的人也需要。

**「无障碍」的设计，往往对所有人都更好用。**

这条原则叫「**通用设计**」。

## 一个例子

字幕。

最初是为听障人士做的。

但现在，在嘈杂的地铁里、在深夜的房间里，**所有人都在用。**
