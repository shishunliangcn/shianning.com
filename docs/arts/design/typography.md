# 字体在说话

🔤 「欢迎光临」。

用楷体，像一家老店；用黑体，像一家便利店；用圆体，像儿童乐园。

**字没变，意思变了。**

## 两种基本类型

**1. 衬线体**

笔画末端有小装饰（像小脚）。

- 例子：宋体、Times New Roman
- 感觉：正式、传统、可信
- 常见于：书、报纸、合同

**2. 无衬线体**

笔画干净，没有装饰。

- 例子：黑体、微软雅黑、Helvetica
- 感觉：现代、简洁、直接
- 常见于：屏幕界面、广告、标志

## 为什么会有这种感觉

一部分是**历史习惯**：书籍长期用衬线体，所以它「像知识」。

一部分是**使用场景**：路牌、手机界面用了无衬线，所以它「像效率」。

**没有哪个更高级，只有合不合适。**

## 几个实用判断

- **正文**要易读：字号够大、行距够宽，比「好看」重要。
- **标题**可以有个性，但别影响识别。
- **数字**在很多场景更好看（钟表、表格）。
- **中英混排**时，选风格接近的字体，别一个太柔一个太硬。

## 一个反例

有些海报为了「有设计感」，用了花体字，结果没人看得清写的是什么。

**设计的第一个任务，是让人看懂。**
