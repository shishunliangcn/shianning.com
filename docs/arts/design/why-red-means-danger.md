# 为什么红色代表危险

🔴 红灯停、消防栓是红的、警告标志是红的。

为什么偏偏是红？

## 一部分是本能

红色在自然界常常意味着：**血、火、有毒的果实**。

人对红色的反应更快——这是进化留下的警觉。

## 一部分是习惯

红色染料在古代很贵（胭脂虫、朱砂），所以红色的东西往往「重要」——皇帝的朱批、教皇的红衣。

**重要 → 权威 → 警告**，这条线慢慢连上了。

## 但颜色是「约定」的

在中国，红色代表喜庆；在股市里，红色代表上涨。

在欧美，红色在股市里代表下跌。

**同一个颜色，两套含义。**

## 设计上的启示

颜色不能单独承担信息。

- 红灯和绿灯，**形状也不同**（圆/箭），因为色盲的人分不清颜色。
- 危险标志除了红色，还配**感叹号、斜纹、形状**。

**好的设计，不把信息只押在一个通道上。**
