# 乱涂也是画画

🖍️ 给他一支笔，他会画到纸外面去。

桌子上、手上、衣服上，都有。

## 他在画什么？

什么也没画。

他在做一件更重要的事：**发现自己的手能让东西出现。**

用力按，线条粗；轻轻划，线条细；画得快，线是直的；画得慢，线会抖。这些是他自己发现的规律，没有人教。

## 一起做：一张大纸

1. 找一张**很大的纸**——越大越好，报纸也行。
2. 给一支**粗蜡笔**，好抓、不容易断。
3. 不规定画什么，只说一句：「这张纸都是你的。」

然后你走开两分钟，让他自己待着。

## 为什么不要说「画的是什么」

因为一旦你问「这是什么」，他就开始想「应该画得像什么」。

2 岁的孩子还画不出「像」的东西。他要先玩够「痕迹」，才可能在某一天说：「这是妈妈。」

## 给家长的话

- **大纸比好笔重要**：纸太小，他会一直画到外面，然后被制止。
- **别纠正是左手还是右手**：2 岁的用手偏好还没定型。
- **把画留下来**：不评价好坏，写上日期收起来。三年后你会感谢自己。
