# 为什么有的画让人觉得「安静」

🖼️ 两幅画，画的都是湖。

一幅让你想深呼吸，一幅让你觉得有点吵。

## 安静来自哪里

**1. 颜色饱和度低**

颜色越鲜艳，视觉越「响」。

灰调、低饱和的颜色，让人放松。

**2. 对比弱**

明暗差别小、边缘柔和，眼睛不用来回跳。

**3. 留白多**

画面不塞满，眼睛有地方休息。

**留白不是「没画完」，是「故意不画」。**

**4. 水平的线多**

水平线让人联想到水面、地平线——稳定、安静。

垂直线有力量，斜线有动感。

## 一个反过来的例子

同样画湖，如果：

- 用高饱和的橙色
- 对比强烈
- 斜线构图
- 画面塞满

**它会变得紧张、热烈，甚至不安。**

**同样的题材，可以完全不同的情绪。**

## 一个练习

选一幅「让你觉得舒服」的画，问自己：

**是颜色？是空的地方？还是线条的方向？**

能说出原因，你就开始「会看」了。
