# 抛接：手和眼睛的对话

🤾 球抛起来，手伸出去——没接住。

再来一次，还是差一点。

## 难点在哪

接球不是「看到球在哪儿，手就过去」。

**你要预判：球会落到哪儿、什么时候到。**

眼睛看到的是「现在的球」，手要准备的是「半秒后的球」。

**这是预测，不是反应。**

## 三个循序渐进的练法

**1. 自己抛自己接**

抛低一点，先建立「球会回来」的感觉。

**2. 抛墙接反弹**

球速更快，逼着眼睛更快判断。

**3. 两人互抛**

距离从一步开始，慢慢拉开。

**别一上来就隔五米。**

## 一个关键

**看球，不要看手。**

新手常犯的错：盯着自己的手，结果球从旁边飞过。

**眼睛盯着球，手会自动跟过去。**

## 为什么值得练

手眼协调是所有球类的基础，也和写字、用剪刀、打字有关。

**它不是「体育课的事」，是神经系统在练习「看—判断—动」的闭环。**
