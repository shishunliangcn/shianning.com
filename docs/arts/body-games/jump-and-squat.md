# 跳一跳，蹲一蹲

🦘 两岁的孩子，一天要跳一百次。

从沙发上跳下来，从台阶上跳下来，从你怀里跳下来。

## 跳是在练什么？

练**平衡**。

跳起来的那一刻，身体是悬空的；落地之前，他要在几十分之一秒里判断：脚往哪儿放、膝盖弯多少、重心偏没偏。

这些判断，脑子记不住，只有身体能记住。

## 一起做：听指令做动作

妈妈说，宝宝做。慢一点，一次一个。

1. **跳**——「跳一跳！」
2. **蹲**——「蹲下来，像小青蛙。」
3. **转圈**——「转一圈。」
4. **单脚站**——「抬起一只脚，站住。」

做对了就夸，做错了就一起笑，再来一次。

## 为什么单脚站最难？

因为要一边站着，一边**不让身体倒**。这需要耳朵里的平衡器官、眼睛、脚底的感觉一起工作。

2 岁的孩子能站 1–2 秒就算很棒了。

## 给家长的话

- **清空场地**：桌角、硬边、地上的玩具先收走。
- **光脚更好**：脚底感觉越丰富，平衡学得越快。
- **别扶着比谁久**：比赛会让他紧张，一紧张就站不住。玩着比着更有效。
