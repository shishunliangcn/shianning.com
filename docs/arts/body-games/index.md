# 🤸 身体游戏

> 造物馆 · 艺术、动手与创想

身体是所有能力的地基。平衡、协调、力量、空间感，都是在玩里长出来的。
这个主题不讲训练计划，只收集「玩着就把身体练了」的游戏。

## 会聊到的问题

- 感统训练到底是什么？需要报班吗？
- 孩子走路老摔跤、怕荡秋千，是哪里没跟上？
- 在家能玩哪些大运动游戏？
- 每天要动多久才够？

## 几个零成本游戏

- **平衡走**：沿着地砖缝走直线，手里端一杯水（从空杯开始）。
- **枕头山**：把靠垫堆起来爬过去，练攀爬与协调。
- **金鸡独立**：单脚站，比谁站得久，闭眼加难度。
- **抛接球**：从大球到小球，从双手到单手。

## 给家长

每天户外一小时，比任何单项训练都重要。
摔跤是学习的一部分，只要场地安全，就让他自己爬起来。
