# 🎨 造物馆

> 艺术、动手与创想

鉴赏是「看」，创作是「做」。这座展馆两样都要。
在这里，评价一件作品的标准不是「像不像」，而是「它有没有说出点什么」。

## 这座展馆有什么

| 主题 | 聊什么 |
| --- | --- |
| [🎵 音乐](/arts/music/) | 声音如何变成音乐，怎么听出门道 |
| [🖼️ 视觉艺术](/arts/visual-art/) | 绘画、摄影与看展，训练会看的眼睛 |
| [🔨 手工创客](/arts/maker/) | 木工、电子与 3D 打印，把想法做出来 |

## 先看这一篇

- [声音是怎么变成音乐的](/arts/music/what-is-sound) —— 从空气振动到一首曲子

## 怎么逛这座馆

1. **先动手，再评价**：亲手做过，才知道难在哪里。
2. **多看原作**：屏幕上的复制品会骗人，色彩和尺幅都失真。
3. **保留过程**：草图、废稿、录音，比成品更能说明你是怎么想的。
