# 一把剪刀能做什么

✂️ 一张 A4 纸、一把剪刀、一瓶胶水。

不花钱，但能做出来的东西比你想象的多。

## 三个十分钟就能做完的

**1. 一根纸条，变成弹簧**

把纸条剪成细长条，一头粘在桌上，另一头绕着一支笔缠起来，再粘住。

松手，它会慢慢弹开——这就是最原始的弹簧。

**2. 一个纸盒，变成抽屉**

鞋盒横着放，中间插一块硬纸板当隔断。外面贴一层纸，写上标签。

**它就变成一个能用的收纳盒。**

**3. 一张纸，承受十本书**

把纸折成瓦楞形（像「W」一样连续折叠），架在两摞书之间。

平铺的纸一压就塌，折过的纸能承重很多倍——**结构比材料更重要。**

## 手比眼睛学得快

看十遍视频，不如剪坏三张纸。

剪歪了、粘反了、结构塌了，这些「错误」都在教你的手：下次该怎么用力。

**做手工真正练的不是手，是「先想一步」的能力。**

## 安全第一

- 剪刀递给别人时，**握住刀刃，把把手递出去**。
- 剪的时候刀刃朝外，不要对着自己或别人的手。
- 纸太厚别硬剪，会滑、会剪到手。
