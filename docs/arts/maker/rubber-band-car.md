# 橡皮筋动力车

🚗 四个瓶盖、一根竹签、一根橡皮筋、一块纸板。

**能跑两米。**

## 原理

你把橡皮筋绕紧——**能量被存在了橡皮筋的形变里。**

松手，橡皮筋恢复原状，把能量放出来，带动轮子转。

**它不是「用完了就没了」，而是「存进去，再放出来」。**

## 做一个

1. 纸板剪成长方形（车身）。
2. 竹签当车轴，穿过车身两侧。
3. 瓶盖中间戳洞，套在车轴上（轮子）。
4. 橡皮筋一头固定车身，另一头绕在**后轴**上。
5. 转几圈后轴，把橡皮筋绕紧，松手。

## 试试改变条件

- **绕的圈数**：圈数越多跑得越远吗？有没有上限？
- **轮子大小**：大轮跑得快还是远？
- **车身重量**：加一块橡皮会怎样？

**一次只改一样。**

## 为什么圈数有上限

绕太多圈，橡皮筋会「叠」在一起，能量反而损失，甚至断掉。

**这就是「极限」——不是越多越好，有一个最优点。**
