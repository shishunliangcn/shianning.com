# 为什么一首歌会卡在脑子里

🎵 一段旋律在脑子里循环。

你不想唱，但它自己响。

**这叫「耳虫」。**

## 为什么是「没唱完」的那段

研究发现，卡住的往往是**副歌**——重复、简单、有起伏的那几句。

而且它常常卡在**半截**：唱到某一句就断，然后又从头开始。

**大脑喜欢「完成」。没完成的旋律，会被反复重放。**

这和心理上「未完成的事更容易被记住」是同一个道理。

## 什么样的歌容易变耳虫

- 节奏快、旋律简单
- 有重复的音型
- 你最近听过（尤其是被动听到的）

**广告歌是这方面的高手。**

## 怎么让它停下来

**1. 把它唱完**

从头到尾完整唱一遍，大脑会觉得「完成了」。

**2. 换一首**

用另一首更洗脑的替换（代价是可能换一只耳虫）。

**3. 做需要注意力的事**

解一道题、读一段难的文章——**工作记忆被占满，旋律就挤不进来。**

**4. 嚼口香糖**（真的有人研究过，有效）

## 一个安慰

耳虫很普遍，绝大多数人都有。

**它不是病，也不是「音乐天赋」的证据。**
