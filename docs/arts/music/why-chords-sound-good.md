# 为什么有的和弦好听

🎹 同时按下 do 和 mi，很舒服。

按下 do 和升 do，很刺耳。

## 声音是波

每个音，都是一个固定频率的振动。

- do：约 262 Hz
- 高八度的 do：约 524 Hz（正好两倍）

**频率成整数比，两个波就会周期性地「对齐」。**

## 为什么对齐就舒服

两个波对齐时，合成后的波形规律、稳定。

不对齐时，波形会互相「打架」，产生快速起伏——听起来就是刺耳、发毛。

## 几个常见的比例

| 音程 | 频率比 | 听感 |
| --- | --- | --- |
| 八度 | 2:1 | 几乎「同一个音」 |
| 五度 | 3:2 | 空、开阔 |
| 四度 | 4:3 | 稳 |
| 三度 | 5:4 | 温暖 |
| 小二度 | 16:15 | 紧张、刺耳 |

**比例越简单，越和谐。**

## 但「好听」不完全由物理决定

不同的音乐传统，喜欢的音程不一样。

**物理决定了「哪些组合不刺耳」，文化决定了「你喜欢哪种」。**
