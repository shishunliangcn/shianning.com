# 🎵 音乐

> 造物馆 · 艺术、动手与创想

音乐是「有组织的声音」。理解这句话，你就同时拿到了欣赏和创作的钥匙。
这门主题从物理和听觉出发，一路走到曲式与风格。

## 会聊到的问题

- 为什么有的和弦听起来「明亮」，有的「忧伤」？
- 一首曲子为什么好听？结构起了什么作用？
- 不同时代的音乐，差别到底在哪？
- 没有乐理基础，能听懂古典乐吗？

## 学习方式

- **听三个版本**：同一首曲子，不同指挥、不同乐器，差别惊人。
- **看谱听**：哪怕只看旋律线，也能抓住结构。
- **唱出来**：能唱准，才说明真的听清了。
