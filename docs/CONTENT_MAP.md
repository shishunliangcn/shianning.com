# 🧭 交叉矩阵 · 动态生长指南

> 知识不分年龄，分的是**认知深度**与**应用场景**。
> 同一个「趣味英语」，2 岁听动物叫声，16 岁练作文结构——主题是纵轴，年龄是横轴。

这份文档不是给读者看的，是给**写作者**用的：横轴找深度，纵轴找主题，交叉点就是下一篇要写的文章。

---

## 一、标签策略（写每一篇前先看这里）

**每篇文章必须至少带一个「主题标签」+ 一个「年龄标签」。**

```yaml
---
title: 遇到校园霸凌，我该怎么保护自己？
tags: [自我保护, 6-12岁]
---
```

| 标签类型 | 取值 | 作用 |
| --- | --- | --- |
| **主题标签** | 26 个主题名之一（天文、自我保护、趣味英语…） | 让文章能被「按主题聚类」 |
| **年龄标签** | `2-6岁` / `6-12岁` / `12-18岁` / `18岁+` | 让读者能「按认知阶段寻路」 |

三条规则：

1. **可以叠加多个年龄标签**（跨段内容），但至少一个。
2. **不要用年龄标签代替主题标签**——「6-12岁」不是主题。
3. 主题标签**必须**是 26 个主题名之一；标签是受控词表（见 `docs/.vitepress/tags.ts`），
   出现词表外的标签会**直接让构建失败**，不会再产生「恒星」「声学」这类散标签。

## 二、架构审计：26 个主题的边界

审计结论：**没有需要合并的主题**，但有 6 组「相邻主题」需要把边界写死，
否则同一篇文章会在两个主题之间来回搬。

| 相邻主题 | 重叠点 | 边界（谁写什么） | 处置 |
| --- | --- | --- | --- |
| 🌿 自然观察 ↔ 🌍 地球与生态 | 都涉及动植物 | **动物 / 植物的个体观察、行为、辨识 → 自然观察**；生态系统的运行、地质与气候 → 地球与生态 | 边界固化，不合并 |
| ⚗️ 趣味实验 ↔ ⚛️ 物理 / 🧪 化学 | 都在做实验 | 强调「动手探究过程」→ 趣味实验；强调「概念与原理」→ 物理 / 化学 | 保留三主题 |
| 🚑 安全急救 ↔ 🛡️ 自我保护 | 都是安全 | **已经受伤后的处置 → 安全急救**；避免陷入危险、面对侵害 → 自我保护 | 保留，勿交叉投稿 |
| 🧩 社会与心理 ↔ 🌼 青春期与性教育 | 都涉及心理 | 群体行为、认知偏差 → 社会与心理；身体变化、亲密关系与边界 → 青春期与性教育 | 保留 |
| 👤 人物 ↔ 🏺 历史 | 都写过去 | 以「一个人」为线索 → 人物；以「事件、制度、结构」为线索 → 历史 | 保留 |
| 🔨 手工创客 ↔ ✏️ 设计 | 都在「做东西」 | 动手制作（材料、工具、电路）→ 手工创客；信息与界面的组织 → 设计 | 保留 |

> 关于「动植物归属」的明确答复：**动物与植物统一归入「自然观察」**，
> 不单独设「动物」「植物」子主题；生态与地质归「地球与生态」。

## 六、怎么写下一篇

1. 在矩阵里挑一个空格（优先补「只有 1 篇」的年龄层：18岁+ 目前最空）。
2. 建文件：`docs/<展馆>/<主题>/<slug>.md`。
3. frontmatter 写 `title`、`description`、`tags`（**主题标签 + 年龄标签**）。
4. 在 `curriculum.ts` 对应主题的 `articles` 里加一行 `{ title, slug }`。
5. 删掉矩阵里的那个选题、在「已完成」加一行。
6. 提交并推送，1 分钟后自动上线。
