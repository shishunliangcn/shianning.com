# 🗺️ 内容地图

这不是给读者看的文章，而是**给自己用的选题清单**。
每个主题列出 3–4 个待写选题，标注适用年龄与叙述视角。

- **年龄段**：2-6 岁 / 6-12 岁 / 12 岁+
- **视角**：写给家长看（家长自己读，再决定怎么跟孩子说） / 直接讲给孩子听（用第二人称写）

> 用法：写完一篇就把对应行删掉，并把它加入 `curriculum.ts` 的 `articles`，
> 侧边栏、标签页、延伸阅读会自动收录。
