# 🧭 养育的方向

> 不解决问题，只谈方向。

书架里的另一类文章，是「孩子打人了怎么办」「不吃饭怎么办」——那些是救火。

这一栏不救火。

这里谈的是更慢、更根本的东西：**你到底想把孩子养成什么样的人**、什么比成绩更重要、你自己该站在什么位置。

## 为什么要有这一栏

救火的文章有用，但有个副作用：**它让人以为育儿就是一连串的危机处理。**

于是每天忙着堵漏，却从没抬头看过方向。

方向错了，方法越熟练，走得越偏。

## 这里会写什么

- 关于「目标」：你想养出一个什么样的人
- 关于「优先级」：什么比成绩更重要
- 关于「身教」：孩子其实在照着你的样子活
- 关于「放手」：什么时候该退后一步
- 关于「节奏」：一年只定一个目标

## 这里不会写什么

- 不写「三招让孩子听话」这类技巧
- 不写「别人家孩子」的比较
- 不给标准答案——有些问题本来就没有统一解
