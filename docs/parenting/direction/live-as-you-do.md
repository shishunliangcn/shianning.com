# 孩子是照着你的样子活的

你跟他说了十遍「要有礼貌」。

然后在餐厅，你对服务员说：「快点，怎么这么慢。」

他听见的不是那十遍。

## 孩子学的是模式，不是句子

小孩的大脑里有一套很原始的机制：**看大人怎么做，然后照做。**

这不是他故意跟你对着干，这是人类学习的方式——比听讲快得多，也牢得多。

所以真正的问题不是「我怎么说服他」，而是「**他每天在看我做什么**」。

## 三个最容易被复制的场景

**1. 你怎么对待比你「地位低」的人**

服务员、快递员、保洁阿姨、家里的老人。

你怎么对他们说话，他就学会怎么对待「不如自己」的人。这一条，比任何礼貌课都管用。

**2. 你怎么面对自己的错误**

打翻了杯子，你是说「哎呀，我来擦」，还是「谁把杯子放这儿的」？

前者教他：错了就处理。后者教他：错了要找人背锅。

**3. 你怎么打发时间**

你刷手机，他就想刷手机。你读书，他会好奇那是什么。

不是「你要读书给他看」，是**你本来就读书，他自然会看见。**

## 身教不是表演完美

这一条很重要，别理解偏了。

身教不是让你在孩子面前演一个完美的人。那反而有害——他会以为「大人从不犯错」，等他发现自己犯错时，会觉得自己有问题。

真正有用的是：**让他看见一个会犯错、也会修复的真实的人。**

- 你可以生气，但要让他看见你怎么平静下来。
- 你可以说错话，但要让他看见你怎么道歉。
- 你可以累，但要让他看见你怎么休息，而不是硬撑到爆炸。

## 一个可以马上做的小事

想一想：**你希望孩子有的那个品质，你自己最近一次做出来是什么时候？**

- 希望他爱读书 → 你上次读完一本书是什么时候？
- 希望他有耐心 → 你上次耐心等一件事是什么时候？
- 希望他不吼人 → 你上次忍住没吼是什么时候？

不用回答我。这个问题本身就是答案。

## 别因此自责

看到这里，你可能会有点沉。

但请记住：**孩子不需要一个完美的榜样，他需要一个真实的、在往前走的人。**

你今天比昨天少吼了一次，他就看见了「人可以改」。
