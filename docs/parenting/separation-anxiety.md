# 如何应对幼儿园的分离焦虑

开学第一周，幼儿园门口总在上演同一种场景：
孩子抱着大人的腿哭，大人一边哄一边回头看，最后两个人都红着眼睛。

先松一口气：**这是正常的**。3 岁左右的孩子，正在建立「看不见的东西依然存在」这个概念。
你走了，他需要真的相信你还会回来——这需要时间和经验，不是讲道理能解决的。

## 为什么会哭得这么厉害

- **客体永久性还不稳固**：看不见妈妈，就难以确信妈妈还存在。
- **环境全变了**：人、气味、规则、厕所，全是陌生的。
- **情绪会传染**：你的犹豫和不舍，他全都读得懂。

## 送园的三个关键动作

### 1. 告别要短、要固定、要说到做到

三步仪式，每次都一样：

1. 蹲下来抱一下
2. 说一句固定的话：「妈妈下午吃完点心就来接你」
3. 交给老师，转身就走

**不要偷偷溜走。** 突然消失会让他下一次更紧地抓住你——因为他不知道你什么时候会不见。

### 2. 给一个明确的时间锚点

幼儿不理解「下午四点」，但理解「吃完点心之后」「睡完午觉之后」。
用他熟悉的日常节点做锚，比看钟表有效得多。

### 3. 允许带一个过渡物

一块小毛巾、一张全家福、一个小挂件。
过渡物的作用是：在你不在的时候，替他携带「家的感觉」。

## 接园时的第一句话很重要

| 别问 | 改问 |
| --- | --- |
| 今天哭了吗？ | 今天玩了什么好玩的？ |
| 有没有人欺负你？ | 今天你跟谁一起玩的？ |
| 想妈妈了吗？ | 妈妈今天很想你，见到你真开心 |

前一种问法在反复提醒「这里是危险的地方」，后一种在帮他积累「这里是安全的地方」的经验。

## 什么时候需要额外帮助

多数孩子的适应期是 **2–4 周**。如果出现下面这些情况，建议和老师沟通，必要时咨询儿科或儿童心理医生：

- 超过 6 周仍然每天剧烈哭闹，无法进入活动
- 明显影响进食、睡眠，体重下降
- 出现退行：已经会说的话不说、已经会自理的事不做
- 反复说身体不舒服，但检查没有发现问题

::: tip 一句话
分离焦虑不是「孩子不够坚强」，而是他在用尽全力确认：你会回来。
你要做的不是让他不哭，而是让他相信。
:::
