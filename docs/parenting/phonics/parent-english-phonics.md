# 亲子英语词表 · 从识物开始

> 不要怕发音不准。你和孩子一起开口，就是最好的启蒙。

下面每个词都可以点一下听读音，旁边是音标。不用背，用的时候现查就行——
孩子看到你在查、在学、在试着说，他学到的比单词本身更多。

**音标怎么看**：`ˈ` 表示重音落在后面那个音节，`ː` 表示长音。音标是美式读音，
和点读按钮一致；英式会有差别，但对孩子来说不重要。

## 给家长的三句话

1. **先听再读**：不确定的时候，点一下喇叭，跟着读一遍再教。
2. **一次一个场景**：今天只逛「认识身边的物品」这 12 个词，用满一周。
3. **不纠正口音，只鼓励开口**：孩子愿意说，比说得像更重要。

::: tip 音标不用背
音标是给你「确认读音」用的，不是给孩子布置的作业。
孩子只需要听到、看到、跟着说；音标是你在犹豫时的一根拐杖。
:::
