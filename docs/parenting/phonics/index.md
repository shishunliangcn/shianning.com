# 🗣️ 亲子英语发音小抄

> 父母的书架 · 一起开口

很多家长不敢教孩子英语，怕自己发音不准，把孩子带偏。

但语言不是先学对再开口的。孩子需要的是**有人愿意和他一起说**，
而不是一个发音完美的老师。你读得慢一点、有点口音，都不影响他建立对这门语言的好感。

这个小抄就是为这件事准备的：**你不需要记音标，点一下就能听，跟着读就行。**

## 怎么用

1. 点单词旁边的喇叭，听一遍标准读音。
2. 自己跟读两遍，再让孩子跟一遍。
3. 每天只挑一个场景，在真实生活里用起来。
4. 说错了不要紧，重来一次就好。
