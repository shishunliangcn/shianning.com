# 打人、咬人、扔东西：他不是坏

😤 抢玩具的时候，他一巴掌拍在小朋友脸上。

你尴尬得想找地缝，一边道歉一边想：这孩子怎么这样。

## 他为什么会打人

因为他**还不会说**。

两岁的孩子，脑子里有强烈的愿望（我要那个车），有强烈的情绪（他不给我，我好气），但嘴巴只能说出两三个词。当语言不够用的时候，身体就会替它说话——推、抓、咬、扔。

这不是道德问题，是**发育阶段**。控制冲动的前额叶，要到二十多岁才完全长好；两岁的孩子，几乎是在用「本能」处理冲突。

这不代表可以不管。它代表：**管的方式，不能是讲道理，也不能是以暴制暴。**

## 当场怎么处理（四步）

1. **先挡手，再说话**。第一时间握住他的手，身体挡在两个孩子中间。动作要稳，不要猛。
2. **一句话命名情绪**：「你很生气，因为他拿走了你的车。」
3. **给一个替代动作**：「生气可以跺脚，可以打枕头，不可以打人。」
4. **带着他修复**：「我们去看看他疼不疼。」让他递一张纸巾、吹一吹。

整个过程不超过一分钟。两岁孩子的记忆很短，事后再讲道理，他已经忘了。

## 三件绝对不要做的事

- **打回去**：「让你也尝尝被打的滋味」——这等于亲自示范「打人可以用来解决问题」。
- **贴标签**：「你怎么这么坏」「你是不是有暴力倾向」——他会把这个标签当成对自己的定义。
- **逼他当场道歉**：两岁的「对不起」只是复读，等情绪过去，带着他做一个修复动作更有意义。

## 长期来看，真正有用的是

- **教词，而不是教规矩**：日常多给情绪词——生气、着急、想要、不要、等一下。词库越大，动手越少。
- **预判高发场景**：抢玩具、累了、饿了的时候最容易动手。提前收走引发争抢的玩具，比事后教育有效。
- **夸具体的行为**：「刚才你等了他一下，这很厉害。」让他知道「等待」也是会被看见的。

## 什么时候该找专业人士

- 四岁以后仍然频繁、无差别地攻击他人
- 攻击伴随自伤（撞头、咬自己）
- 在多个环境（家里、托班、户外）都持续发生，且越来越重
