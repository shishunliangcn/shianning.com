# 屏幕：不是能不能看，是看完之后

📱 一顿饭要靠动画片才能吃完。

出门一哭，手机递过去，世界安静。

你知道不该这样，但你也需要那十分钟的安静。

## 先把「时长」这件事说清楚

主流的儿科建议大致是：

| 年龄 | 建议 |
| --- | --- |
| 18 个月以下 | 除视频通话外，尽量不看 |
| 18–24 个月 | 只看高质量的，且**大人一起看、一起说** |
| 2–5 岁 | 每天不超过 1 小时高质量内容 |

但比时长更重要的，是下面两个问题。

## 问题一：它挤掉了什么

屏幕几乎不占用「无聊的时间」，它占用的是**别的时间**：

- 户外跑跳的时间
- 自己摆弄积木、发呆、观察蚂蚁的时间
- 和你一来一回说话的时间

一个两岁孩子每天清醒的时间只有十小时左右。屏幕多占半小时，就是别的地方少半小时。

**判断标准**：如果他的户外、睡眠、和人的互动都还够，那半小时屏幕不算罪过；如果这些都被挤掉了，那就该调整。

## 问题二：关掉之后发生了什么

这是最容易被忽略的一点。

屏幕是**强刺激**，关掉的一瞬间，孩子从高刺激掉回现实，会产生明显的落差——哭闹、烦躁、无所适从。

所以真正要设计的不是「看多久」，而是**「怎么结束」**：

1. **提前预告**：「再看一集，看完我们就关。」
2. **让他自己关**：把遥控器交给他，让他按那个关闭键。
3. **立刻接上一个动作**：关掉之后马上说「我们去阳台看看有没有小鸟」，不要留出空档。

## 三条实用规则

- **卧室不放屏幕**：这条比任何时长限制都有效。
- **吃饭时不开**：餐桌是用来吃饭和说话的。
- **大人也别刷**：你在孩子面前刷手机的时间，比你想的要长。

## 两岁孩子可以看什么

- 节奏慢、画面简单、有真实语言的（不要快切、不要强音效）
- 有对应的现实活动可以接上（看完动物，去看窗外的鸟）
- 时长可控、能一集一集停下来的
