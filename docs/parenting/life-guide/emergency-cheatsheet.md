# 紧急情况速查表

🚨 这一页不放原理。

**只放「现在该做什么」。**

原书第 13 节有 49 条，这里按家庭最常见的场景重排，每条一句话。

## 通用顺序

> **先保自己 → 再呼救 → 再施救 → 最后送医。**

**先保自己不是自私。救不了自己，就救不了别人。**

## 一、有人倒地

| 情况 | 做什么 |
| --- | --- |
| 叫不醒、没有正常呼吸 | **立刻打 120，开始胸外按压** |
| 老人摔倒 | **别急着扶**，先问哪里疼、能不能动腿 |
| 抽搐倒地 | 移开周围硬物，**不要往嘴里塞东西**，记录时间 |
| 糖尿病人突然发抖、出冷汗 | 清醒就给糖水，**昏迷不要喂** |

## 二、噎住

| 情况 | 做什么 |
| --- | --- |
| 还能咳嗽、能出声 | **鼓励他用力咳**，不要拍背、不要掏 |
| 不能咳、不能说、脸发紫 | **海姆立克**：肚脐上方，向内向上冲击 |
| 一岁以下婴儿 | **背部拍击 5 次 + 胸部按压 5 次**，不用腹部冲击 |
| 只有自己一个人 | 用椅背顶住上腹部 |

详细做法：[噎住了：那三分钟能救命](/life/safety-first-aid/choking)

## 三、外伤与烫伤

| 情况 | 做什么 |
| --- | --- |
| 大出血 | **直接压住伤口**，加压包扎，别频繁掀开看 |
| 烫伤 | **流动冷水冲 15–20 分钟**，不涂牙膏酱油，不敷冰 |
| 被猫狗咬伤 | 肥皂水冲洗 15 分钟，**尽快打疫苗** |
| 异物扎进身体 | **不要拔**，固定住送医 |
| 怀疑骨折 | **不要动**，就地固定 |
| 恒牙整颗撞掉 | 捏牙冠（不碰牙根），泡牛奶或生理盐水，**一小时内**就医 |

详细做法：[烫伤后的第一件事](/life/safety-first-aid/burns) ｜ [扭伤了，先冷敷还是热敷](/life/safety-first-aid/sprain) ｜ [流鼻血，别仰头](/life/safety-first-aid/nosebleed)

## 四、中毒、火灾、意外

| 情况 | 做什么 |
| --- | --- |
| 触电 | **先断电**，用干燥木棍挑开，不要直接拉人 |
| 一氧化碳报警 | 开窗、关气源、人撤到室外，**不要开灯点火** |
| 误服药物/清洁剂 | **保留瓶子**，打急救电话，**不要自己催吐** |
| 化学品溅到皮肤 | 大量清水冲 15 分钟以上 |
| 中暑（皮肤干热、意识模糊） | 打 120，同时降温，**不要喂水** |
| 火灾 | **低姿贴地、关门、不坐电梯** |
| 有人溺水 | **不要贸然下水**，抛漂浮物、呼救 |
| 孩子吞了纽扣电池/磁珠 | **立刻就医**，不要等症状 |
| 有人喝醉 | **侧躺**，不要让他一个人仰睡 |

详细做法：[触电、溺水、中暑](/life/safety-first-aid/three-emergencies) ｜ [着火了，烟比火更危险](/life/life-skills/fire-escape) ｜ [冬天取暖，小心这个看不见的杀手](/life/life-skills/heating-safety)

## 五、野外

| 情况 | 做什么 |
| --- | --- |
| 迷路 | **留在原地**，不要乱走；发信号、保温 |
| 发抖、说话含糊 | 是失温：换干衣服、裹保温毯、慢慢复温 |
| 被蛇咬 | **不要切、不要吸**，保持不动，尽快就医 |
| 遇到熊/野猪/野狗 | 不要跑，慢慢后退，不要直视逼近 |
| 雷雨 | 远离树下、高地、水边，蹲下抱膝 |
| 上高原 | **慢慢升**，不要一天爬太多 |
| 被蜱虫叮住 | 用镊子贴近皮肤拔出，**不要硬拽、不要烧** |
| 野外的水 | **烧开再喝** |

## 六、打之前先想好说三件事

打 120 时，说清楚：

1. **在哪里**（小区、楼栋、门牌，或者最近的标志物）
2. **发生了什么**（几个人、什么情况、有没有意识）
3. **你的电话**

**别先挂电话——接线员会问你该怎么做。**
