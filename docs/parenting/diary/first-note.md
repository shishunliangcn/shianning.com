# 写在这个学堂诞生之初

> 这里没有长篇大论的教育理论，只有爸爸妈妈在陪你长大的过程中，
> 每一次感动、困惑与成长的瞬间。

## 为什么要有这个手记

建这个学堂的时候，我们想的都是「该教什么」：天文、英语、自我保护、怎么洗手。
清单越列越长，越列越像一张任务表。

直到有天晚上，你在床上翻来覆去不肯睡，我问了三遍「怎么了」，
你才小声说：「爸爸，我怕明天那个小朋友还是不跟我玩。」

那一刻我忽然明白：**知识可以慢慢学，但这样的时刻，过去了就过去了。**

于是就有了这个手记。它不负责解答问题，只负责把问题记下来。

## 我们想记下的三件事

**一、那些突然被打动的瞬间。**
你第一次自己系上鞋带，抬头看我，眼睛亮得像发现了新大陆。
那天的日期我记不清了，但那个眼神我记得。

**二、那些我们没做好的时刻。**
有一次我吼了你，你愣在那里，眼泪没掉下来。
那晚我在厨房站了很久。这种时刻更值得写，因为它是真的。

**三、那些说不清的困惑。**
比如：要不要逼你练琴？比如：你撒谎了，是该先讲道理还是先抱抱？
我们到现在也没有答案，但写下来，至少知道自己在哪里卡住。

## 写给史安宁

等你长大到能读懂这些字的年纪，大概会觉得这些事很幼稚吧。

但我想让你知道：我们不是天生就会当爸妈的。
我们是边做边学，边犯错边改，很多时候是你教会了我们。

这个学堂里所有的知识，都是我们想给你的翅膀。
而这个手记，是我们想留给你的另一件东西——**你被爱着的证据。**

## 关于这个学堂

它叫「史安宁的小学堂」，五座展馆，二十六个主题。
没有年级，不排名次，也不催你。

你可以两岁来看动物怎么叫，也可以十六岁来看怎么用英语写作文。
我们只希望，很多年以后你想起它，记得的不是「学过多少」，
而是「那是我爸妈为我做的一件事」。
