# ✍️ 陪伴手记

> 父母的书架 · 记录与陪伴

这里不放方法论。
育儿文章教你「怎么做」，手记只记录「那一刻我是什么感觉」。

## 会写什么

- 第一次听到你完整说出一句话的那个下午
- 我冲你发了火，然后在厨房里站了很久
- 你把自己的饼干分给小朋友，我在旁边假装没看见
- 那些我说不清是对是错的瞬间

## 不会写什么

- 不写「三步搞定」「五个技巧」
- 不写别人家的孩子
- 不写我其实没做到的漂亮话
