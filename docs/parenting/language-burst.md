# 只会说几个词，要不要紧？

🗣️ 邻居家同龄的孩子已经会说整句话了。

你家这位还只会指着东西「嗯嗯」。

要不要紧？

## 先看几个参照点

每个孩子开口的时间不一样，但有几条大致的线：

| 年龄 | 通常能做到 |
| --- | --- |
| 1 岁半 | 会说 10–20 个词，能听懂简单指令 |
| 2 岁 | 约 50 个词，开始把两个词拼在一起（「妈妈抱」「还要奶」） |
| 2 岁半 | 短句变多，能说三四个字 |
| 3 岁 | 能说简单句子，陌生人基本能听懂 |

**关键不是「多少个」，而是「有没有在进步」**：这个月比上个月多说几个词，就是好信号。

## 真正影响语言的三件事

**1. 有没有人和他「轮流」**

语言是乒乓球，不是广播。你说一句，等他说（哪怕只是「嗯」），你再说。**等待**比说多少更重要。

**2. 他听到的是不是「解说」，而不是「指令」**

- 指令：「把鞋穿上」「别动」
- 解说：「我们要出门了，先穿鞋。你的鞋在这儿，左脚，右脚。」

解说式语言里有名词、动词、顺序词，这些是句子的零件。

**3. 屏幕算不算输入**

不算。屏幕里的语言不会根据他的反应调整，孩子学不到「轮流」。**看屏幕的时间，替代的是对话的时间。**

## 明天就能做的三件事

1. **解说你正在做的事**：洗菜、叠衣服、开车，边做边说。「这个土豆上有泥，我们洗一洗。」
2. **等三秒**：问完问题，心里数三秒。大人常常等不到一秒就自己接话了。
3. **扩展他的词**：他说「狗狗」，你说「对，一只黑色的狗狗，它在跑。」——只加一点点，不要变成长篇。

## 什么时候该去评估

如果出现下面任何一条，建议去儿保或儿童语言门诊看一看，早看早安心：

- 两岁还不会说两个词的组合（如「妈妈抱」）
- 叫名字经常没有反应，怀疑听力
- 一岁后曾经会说某些词，后来反而不说了（语言倒退）
- 不会用手指指东西给你看，也不看你的眼睛
- 三岁后说话大多数陌生人听不懂
