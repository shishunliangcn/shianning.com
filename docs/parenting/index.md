# 📚 父母的书架

> 按年龄分层的育儿实操笔记

这里不放鸡汤，只记那些真正用得上的动作和句子。
每个阶段挑一两个最让人头疼的问题，写清楚「为什么会这样」和「明天可以怎么做」。

## 🗣️ 亲子英语发音小抄

怕自己发音不准？不用怕。这里按日常场景整理了常用的亲子英语，

## 怎么用这个书架

1. **先看「为什么」**：理解发展阶段，比记住话术更重要。
2. **只挑一条先做**：一次改一个动作，改得动才算数。
3. **允许自己做不到**：育儿是长期工程，不是考试。

::: tip 一个提醒
这里的建议面向普遍情况。如果孩子出现持续的进食睡眠问题、自伤念头或明显退行，
请优先寻求儿科或儿童心理专业人士的帮助——那不是「不听话」，是需要被看见。
:::
