# 辅导作业不崩溃：培养内驱力的3个秘诀

辅导作业是很多家庭每天最激烈的一小时。
家长越盯越急，孩子越催越慢，最后写完了，两个人都不开心。

问题的根源往往不在作业，而在**这件事到底是谁的事**。
当孩子觉得「我是为妈妈写的」，所有的方法都会失效。

## 内驱力的三个来源

心理学里有个很稳的框架：一个人愿意主动做一件事，通常因为三种感受。

| 感受 | 含义 | 缺了会怎样 |
| --- | --- | --- |
| **自主感** | 这是我选的 | 拖延、敷衍 |
| **胜任感** | 我做得到 | 畏难、逃避 |
| **归属感** | 做不好也有人说我 | 焦虑、撒谎 |

下面三个秘诀，分别对应这三样。

## 秘诀一：把「监督」换成「共处」

坐在旁边盯着，传递的信息是「我不信任你能做好」。
换成：**你也在旁边做自己的事**——看书、回邮件、写东西。

同一个空间，各自安静地做事。
他抬头能看到你在，但不是在看他的本子。

> 这一步最反直觉：你越不盯，他反而越容易进入状态。
> 因为他终于有机会感受到「这是我在完成」。

## 秘诀二：把大任务切成看得见终点的小块

「去写作业」是一团模糊的压力；
「先把数学第 3、4 题做完，15 分钟，做完休息 5 分钟」才是可执行的动作。

- 用计时器，不用催促。
- 从**最容易**的一科开始，先拿到「我开始了」的感觉。
- 休息就是休息，不要「顺便背两个单词」。

## 秘诀三：表扬过程，不表扬结果

| 别夸 | 改夸 |
| --- | --- |
| 你真聪明 | 你刚才自己检查了一遍，很细心 |
| 考得真好 | 这周你每天都复习了 20 分钟，我看到了 |
| 终于写完了 | 你卡在那道题上没放弃，这点很厉害 |

夸结果会让孩子回避难题（怕失去「聪明」的标签）；
夸过程会让他愿意挑战，因为努力本身被看见了。

## 三句可以直接用的话

1. 「这道题你想先自己想 5 分钟，还是我们一起看第一步？」
2. 「今天的计划你定，你说了算，我负责陪你。」
3. 「写错了没关系，错题才是真正能学到东西的地方。」

## 不要做的事

::: warning 这些做法会直接杀死内驱力
- **抢笔代劳**：你写得比他快，他就再也不想写了
- **拿别人比较**：「你看人家」只会让他把学习等同于羞辱
- **用奖励交易**：「写完给你玩手机」会把内在动机换成外在筹码
- **情绪化收尾**：每天以争吵结束，作业就成了一件可怕的事
:::

::: tip 一句话
你没法替孩子产生动力，但你可以不把它压灭。
少一点监督，多一点信任，他才有机会把「要我学」变成「我要学」。
:::
