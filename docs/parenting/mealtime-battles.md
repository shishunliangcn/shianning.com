# 「再吃一口」：吃饭为什么变成拉锯战

🍚 一碗饭喂了四十分钟。

孩子在餐椅上扭来扭去，你举着勺子跟在后面：「最后一口，就一口。」

最后一口之后，还有最后一口。

## 孩子为什么不好好吃饭

大多数时候，不是他不想吃，是**他不想被喂**。

两岁是自主性爆发的时候。他要自己拿勺子、自己决定吃哪块、自己决定什么时候停。你越喂，他越要夺回控制权——哪怕代价是饿肚子。

还有一个更简单的原因：**他不饿**。上午的饼干、下午的酸奶、随时能喝到的奶，把饥饿感填满了。饿，才是最好的调味料。

## 大人该管什么，不该管什么

| 大人负责 | 孩子负责 |
| --- | --- |
| 什么时候吃 | 吃不吃 |
| 吃什么（桌上摆什么） | 吃多少 |
| 在哪儿吃 | 吃多快 |

这条分界线叫「喂养分工」，是儿科营养里最实用的一条：**你管供给，他管摄入。** 一旦你越界去管「吃多少」，战争就开始了。

## 明天可以试的四件事

1. **定时定点**：一天三餐 + 两次点心，坐餐椅吃，吃完就下桌。
2. **收走就收走**：他说不吃了，平静地说「好，那这顿结束了」，把饭收走。中途不加餐、不给零食，等到下一次点心。
3. **每样给一点点**：盘子里一次别超过三勺，吃完再添。大盘子会让他有压力。
4. **让他自己动手**：脏就脏，铺张报纸在椅子下面。自己抓着吃的两岁孩子，比被喂的两岁孩子吃得更主动。

## 不要做的三件事

- **追着喂**：这一口省下了，下一顿更费劲。
- **用动画片换饭**：注意力被屏幕拿走，孩子会忘记「饱」是什么感觉。
- **把饭桌变成评价现场**：「你看人家吃得多好」——他听到的不是鼓励，是比较。

## 什么时候该找医生

如果出现下面这些情况，别再和饭桌较劲，去看儿科或儿童营养门诊：

- 体重连续两个月不增或下降
- 吞咽困难、频繁呛咳
- 只吃极少数几种食物，持续超过一个月
- 吃饭时反复呕吐或腹痛
