# 🔢 数学思维

> 灵犀馆 · 语言与逻辑魔法

数学不是算得快，是想得清。
这门主题关心的是：怎么把一句模糊的话变成可以证明的命题，怎么在不确定中做判断。

## 会聊到的问题

- 0.999… 到底等不等于 1？
- 为什么「巧合」其实没那么巧？
- 一个证明要写到什么程度才算完整？
- 数学怎么帮我们做现实中的决定？

## 学习方式

- **先问「为什么可以这样」**：每一步都要有依据。
- **举反例**：证明难，推翻往往只需要一个例子。
- **用图思考**：函数、概率、几何，画出来就清楚一半。

## 准备

- 纸和笔（不是屏幕）：数学需要涂改
- 一个「我卡住了」清单，过一周再看，常常自己就通了
