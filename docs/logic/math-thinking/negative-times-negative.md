# 负数乘负数，为什么得正

➖ 3 × 2 = 6，这个好懂：三组两个。

那 **(−3) × (−2) = 6** 是什么意思？

**「负三组负两个」——说不通。**

## 换个角度看

数学不怕「不好懂」，怕「规则打架」。

所以我们先假设一个别的结果，看看会发生什么。

## 如果 (−3) × (−2) = −6 会怎样

我们知道：**a × (b + c) = a×b + a×c**（分配律）。

取 a = −3，b = 3，c = −3：

左边：**(−3) × (3 + (−3)) = (−3) × 0 = 0**

右边：**(−3)×3 + (−3)×(−3) = −9 + ?**

要让左右相等：

**−9 + ? = 0 → ? = 9**

**所以 (−3) × (−3) 必须等于 9。**

## 结论

**「负负得正」不是谁规定的，是为了让分配律继续成立，被迫的选择。**

**换一种规则，你熟悉的整个算术就会崩。**

## 另一个直觉

**「欠债」的模型**：

- 你有 3 笔债，每笔 2 元 → 3 × (−2) = −6（你欠 6 元）
- 现在**免掉**这 3 笔债 → (−3) × (−2) = +6（你多了 6 元）

**「去掉负数」，等于「加上正数」。**
