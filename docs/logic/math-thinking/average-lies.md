# 平均数为什么会骗人

📊 「我们公司平均工资一万。」

你入职后发现自己拿五千。

**那个一万是真的吗？可能是。**

## 一个例子

十个人，九个人月薪 5000，一个人月薪 55000。

**平均 = (5000×9 + 55000) ÷ 10 = 10000。**

**平均工资确实是一万。**

但十个人里有九个拿五千。

## 为什么

**平均数会被极端值「拉」过去。**

那个 55000 把平均值拉高了，但它不代表任何人。

## 更可靠的另一个数：中位数

把所有人的工资从低到高排好，**中间那个数**。

上面例子里，中位数 = **5000**。

**中位数不会被极端值带偏。**

## 什么时候用哪个

- **平均数**：数据比较均匀时，它能代表整体水平
- **中位数**：有极端值时，它更接近「典型情况」

**看到「平均」两个字，先问一句：有没有人被平均掉了？**

## 生活里的例子

- 「平均身高」还好用，因为身高不会差太多
- 「平均收入」容易误导，因为收入差距大
- 「平均房价」几乎没意义——豪宅会把均值拉高
