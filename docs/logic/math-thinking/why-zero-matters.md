# 为什么 0 很重要

0️⃣ 你三岁就会写 0。

但在人类历史上，0 作为一个「数」，比 1、2、3 晚出现了很久很久。

**因为「没有」这件事，很难被当成「东西」。**

## 一、没有 0 的世界

古罗马人用字母记数：I、V、X、L、C、D、M。

写 105，是 **CV**。

**你能看出「中间有一位是空的」吗？**

看不出来。因为罗马数字根本不关心「位置」——它只关心「加起来是多少」。

**没有 0，就没有「占位」这个概念。**

## 二、0 真正的功劳：位置记数法

我们今天写 105，意思是：

```
1 个百 + 0 个十 + 5 个一
```

那个 0 **不是「没有」**，它在说：**这一位是空的，请占住这个位置。**

有了这个约定，同一个数字符号，放在不同位置就代表不同的量级。

**这是数学史上最重要的发明之一。**

它让「12」和「102」不会混淆，让竖式加法成为可能，让大数变得可写。

## 三、0 是「发明」出来的

- 古巴比伦人用两个斜楔表示空位，但那只是一种记号，不是数。
- 公元 7 世纪，印度数学家把 0 当作一个**可以参与运算的数**。
- 之后经阿拉伯世界传到欧洲，欧洲人一开始还抗拒——「什么都没有，怎么能算数？」

**「0 是一个数」这句话，人类花了一千年才接受。**

## 四、0 带来的麻烦

**除以 0 没有意义。**

「6 ÷ 0 = ?」的意思是「几个 0 加起来等于 6」。

**没有任何数能满足。** 所以数学不说「等于无穷大」，而说「无定义」。

计算机遇到除以 0 会直接报错——**这是数学在保护程序。**

## 五、0 的性格

- 它是**唯一一个既不是正数、也不是负数的数**
- 加法里的「什么都不改变」：a + 0 = a
- 乘法里的「归零」：a × 0 = 0
- 它没有倒数（因为 1/0 不存在）

**一个符号，同时是「空」和「支点」。**

## 六、一个可以想的类比

想象你在写一本书的页码。

如果没有 0，第 10 页、第 100 页就没法写。

**0 让「空位」有了名字，于是长长的数字才能被写下来、算下去。**
