# 为什么 0 很重要

0️⃣ 你从小就会写 0。

但 0 是个很晚才被人类接受的数。

## 没有 0 的世界

古罗马人用 I、V、X、L、C 写数字。

写「一百零五」是 CV。看不出「中间是空的」这回事。

**没有 0，就没法用「位置」来表示数。**

## 0 带来了「位置记数法」

有了 0，才能这样写：

```
105  =  1个百 + 0个十 + 5个一
```

那个 0 不是「没有」，它是在说：**这一位是空的，请占住位置。**

没有它，105 和 15 就分不清了。

## 0 带来的麻烦

0 不能做除数。

因为「6 ÷ 0 = ?」的意思是「几个 0 加起来等于 6」——没有这样的数。

**所以除以 0 是「无意义」，不是「等于无穷大」。**

## 0 的地位

- 它是**唯一一个既不是正数也不是负数的数**。
- 它是加法的「单位元」：a + 0 = a。
- 它是乘法的「零元」：a × 0 = 0。

**一个小小的符号，撑起了整个算术。**
