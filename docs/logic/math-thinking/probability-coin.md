# 抛十次硬币都是正面，正常吗

🪙 抛硬币，出现正面的概率是 1/2。

连续十次都是正面，概率是 (1/2)¹⁰ = **1/1024**。

看起来极难，但全世界每天有几十万人在抛硬币——**它总会在某个人身上发生。**

## 关键在这里

现在，你已经抛出了十个正面。

**下一次是正面的概率是多少？**

还是 **1/2**。

## 为什么不是「该出反面了」

因为硬币没有记忆。

它不知道前面发生了什么。每一次抛，都是独立事件。

「已经连续十次正面，所以下次更可能是反面」——这叫**赌徒谬误**。

## 那「一千次里大约五百次正面」是怎么回事

那是**大数定律**：抛的次数足够多，正面比例会接近 1/2。

但它靠的是「后面的次数把比例拉回来」，**不是靠「补偿前面的偏差」**。

## 一个真实的应用

抛 20 次，记录正反。

看看最长的连续同面有几次——大多数人会惊讶地发现，连续四五次很正常。

**人对「随机」的直觉，通常比真正的随机更「均匀」。**
