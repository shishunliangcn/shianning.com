## 怎么逛这座馆

1. **追问到「为什么」**：规则背后总有原因，找到原因就不用死记。
2. **用输出检验输入**：能讲给别人听，才算真的学会。
3. **警惕说得漂亮的错话**：逻辑是防身术。
