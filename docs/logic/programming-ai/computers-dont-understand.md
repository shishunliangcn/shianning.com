# 电脑听不懂人话

💻 你对电脑说：「帮我把这些数字排好序。」

它一动不动。

不是它笨，是它真的听不懂。**电脑不认识「排序」，它只认识几个极其简单的动作。**

## 它到底会什么

一台电脑，本质上只会做这几件事：

1. **读**一个数（从内存里拿出来）
2. **算**（加、减、比较大小）
3. **跳**（如果满足条件，就去另一行继续）
4. **写**（把结果放回去）

就这些。

你看到的视频、游戏、聊天软件，全都是这四件事，被安排了上亿次。

## 什么叫「算法」

**算法就是：把一件复杂的事，拆成一串它能执行的简单动作。**

举个例子：找出三个数里最大的那个。

```
先拿第一个数，当作「目前为止最大的」
再看第二个：比它大吗？大就换掉
再看第三个：比它大吗？大就换掉
最后手里剩下的，就是最大的
```

这段话，电脑能执行。因为它只用了「读」「比较」「换」。

## 一个更真实的例子：排序

把一堆数字从小到大排好，电脑不会「看」，它只能两两比较。

最简单的办法叫「冒泡」：

- 比较相邻的两个数，顺序错了就交换
- 从头到尾走一遍，最大的数会「冒」到最后
- 重复这个过程，直到全部排好

它很慢，但它一定对。

**算法的好坏，往往就是「同样的结果，谁做的步骤少」。**

## 那 AI 呢

AI 也是程序，但它不靠人写规则，而是**从大量例子里自己找规律**。

比如你给它看几百万张猫的照片，它会慢慢学会「什么样的图案大概率是猫」。

但它学的其实是**「什么词后面常跟什么词」**——所以它会自信地说出错误的话。

**它不是在「想」，它是在「猜下一个最可能的词」。**

知道这一点，你就不会把它的每句话都当成真理。
