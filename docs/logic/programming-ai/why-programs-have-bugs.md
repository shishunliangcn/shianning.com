# 为什么程序会有 bug

🐛 程序崩了。

查了半天，发现少写了一个逗号，或者把 `<` 写成了 `<=`。

**为什么不一次写对？**

## 原因一：电脑只会「照做」

它不理解你的意图。

你想的是「算平均分」，它执行的是「先加再除」——**除的时候用了错误的个数。**

**它不会提醒你「你是不是想错了」，它只会错给你看。**

## 原因二：情况太多

一个程序可能有：

- 正常的输入
- 空的输入
- 特别大的数
- 负数
- 网络断了

**你只测试了第一种。**

## 原因三：模块之间的误解

A 以为 B 会传给我一个数字，B 传了一个文字。

**各自都「没错」，合起来就错了。**

## 怎么减少 bug

**1. 一次只改一点点**

改十行再测，错了不知道是哪行。

**2. 先想边界**

空、零、最大、最小——这些地方最容易出问题。

**3. 让别人读一遍**

**自己写的东西，自己读不出来错。** 因为你的脑子会自动补上「我以为我写的」。

## 一个比喻

写程序像写说明书。

**你写的不是「我想做什么」，是「别人照着做，必须不出错」。**

**这个「别人」很笨，但它很快。**
