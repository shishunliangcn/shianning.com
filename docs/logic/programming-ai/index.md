# 🤖 编程与AI

> 灵犀馆 · 语言与逻辑魔法

编程是把想法翻译成机器能执行的步骤；AI 则是让机器从数据里自己找规律。
理解这两件事，你才不会被「智能」二字唬住。

## 会聊到的问题

- 为什么计算机只认识 0 和 1？
- 一段代码怎样才能既正确又好读？
- 大模型到底在做什么？它为什么会「胡说」？
- 算法推荐是怎么影响我们看世界的？

## 学习方式

- **先写出能跑的，再写好**：完美主义是初学者最大的敌人。
- **读报错**：错误信息通常已经把答案说清楚了。
- **做小工具**：给自己解决一个真实的小麻烦，比做十个练习有用。

## 准备

- 一台能装软件的电脑
- 一个真实的小需求：「我想自动整理下载文件夹」
