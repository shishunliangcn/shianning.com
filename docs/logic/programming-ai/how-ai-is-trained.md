# 训练 AI 是怎么回事

🤖 你想让电脑认猫。

传统做法：写规则——「有尖耳朵、有胡须、四条腿」。

**但猫有各种姿势、各种颜色，规则永远写不完。**

## 换个做法：给例子

给电脑看一百万张照片，标好「这是猫」「这不是猫」。

它一开始乱猜，然后根据「错了多少」调整内部参数。

**反复调整几百万次，它慢慢「会」了。**

**它不是学会了「猫的概念」，是学会了「什么图案大概率对应猫这个标签」。**

## 这就是「训练」

- **数据**：例子
- **参数**：它内部无数个可以调整的数字
- **损失**：它错得有多离谱
- **调整**：往「错得更少」的方向改

**没有「理解」，只有「调参」。**

## 为什么它会胡说

因为它学的是**「什么词后面常跟什么词」**，不是「什么是真的」。

它没有事实数据库，只有**统计规律**。

所以在它不熟悉的领域，它会用「听起来很像」的方式编造——而且语气很自信。

**这不是它故意骗你，是它的工作方式本来就是这样。**

## 一个判断方法

问它一个**你自己知道答案**的问题。

答对了，不代表它在别的问题上也可靠；
答错了，说明它在这个方向上的训练不足。

**AI 是很好的助手，不是可靠的信息源。**
