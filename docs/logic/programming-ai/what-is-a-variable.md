# 什么是变量

📦 程序要记住东西。

记在哪儿？记在**变量**里。

## 变量是一个盒子

想象一个盒子，上面贴着标签：`年龄`。

你把 `8` 放进去。之后程序每次看到 `年龄`，就知道去那个盒子里拿。

```
年龄 = 8
年龄 = 年龄 + 1     ← 现在盒子里是 9
```

**变量不是数学里的 x，它是一个可以随时被替换内容的容器。**

## 为什么要起名字

因为程序里盒子很多。

叫 `a`、`b`、`c` 的盒子，过两天你自己都不记得装了什么。

叫 `score`、`lives`、`playerName` 的，一眼就懂。

**好的名字，是给未来的自己留的说明书。**

## 三种常见类型

- **数字**：`3`、`3.14`
- **文字**（字符串）：`"小明"`
- **真假**（布尔）：`true` / `false`

类型不同，能做的事实也不同——两个数字能相加，两个文字「相加」是把它们接起来。

## 一个常见的错误

```
分数 = "10"      ← 这是文字
分数 + 5         ← 结果是 "105"，不是 15
```

**因为文字相加是「拼接」，不是「计算」。**

## 为什么值得懂

你写的每一行程序，几乎都在读变量、改变量、或者用变量做判断。

**理解了盒子，就理解了程序的一半。**
