# 循环：让电脑做重复的事

🔁 让人抄一百遍课文，他会烦。

**电脑抄一百万遍，它不会。**

## 为什么需要循环

如果要计算「1 加到 100」：

写 99 个加号？太蠢了。

```
sum = 0
i = 1
循环：只要 i <= 100
    sum = sum + i
    i = i + 1
```

**四行，做完了。**

## 循环的三个部分

1. **从哪儿开始**：`i = 1`
2. **什么时候停**：`i <= 100`
3. **每轮做什么**：加进去，然后 i 加一

**缺了「什么时候停」，程序就永远转下去**——这叫死循环。

## 另一种循环：对每个

「把这 50 个学生的分数加起来」——不需要数字编号。

```
对每一个 学生：
    总分 = 总分 + 学生的分数
```

**这种写法更自然，也更不容易错。**

## 循环真正难的地方

不是语法，是**边界**：

- 从 0 还是从 1 开始？
- 是 `<` 还是 `<=`？

**差一个，结果就全错。** 程序员管这叫「差一错误」。
