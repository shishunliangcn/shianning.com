# 故事为什么要有冲突

📖 「小明早上起床，吃了早饭，去上学，放学回家，睡觉。」

这不算故事。

**它只是「发生了什么」。**

## 故事需要一个「但是」

「小明想考第一，**但是他**一翻开书就困。」

「小女孩想去森林，**但是**妈妈说不许。」

**有了「但是」，事情才有张力。**

## 冲突有三种

**1. 人和人**

他想去，别人不让。两个人都没错，但目标相反。

**2. 人和环境**

洪水、贫穷、规则、命运。

**3. 人和自己**

想变好，又管不住自己；想说实话，又怕失去。

**这一种最难写，也最动人。**

## 为什么必须要有

因为读者关心的是**「他会怎么办」**。

没有冲突，就没有「怎么办」——读者读不下去。

**冲突不是「打起来」，是「卡住了」。**

## 一个好故事的形状

```
他想要 A
→ 但 B 挡着他
→ 他试了方法 1，失败
→ 他试了方法 2，代价更大
→ 他必须做出选择
→ 结果改变了他
```

**「改变了他」这一步，是故事的意义所在。**
