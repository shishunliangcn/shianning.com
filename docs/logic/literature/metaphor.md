# 比喻为什么有用

🌙 「月亮像一只小船。」

这句话没有一个字在解释月亮。但你脑子里出现了画面。

## 比喻在做什么

它把一个**陌生的东西**，挂到一个**你熟悉的东西**上。

抽象的东西最难懂，比喻给它一个形状。

- 「时间是一条河」——时间变得可以流、可以回溯、可以一去不回。
- 「他是个冰箱」——不用解释，你立刻懂了他的冷。

## 好的比喻长什么样

**1. 准**

不只是「像」，而是像在**关键那一点**上。

「月亮像小船」——像在弧度和「漂」的感觉上。

**2. 新**

「脸红得像苹果」用了三百年，已经死了。

好的比喻，是在两个本来无关的东西之间，突然搭上一根线。

## 一个练习

拿一个抽象的词：孤独、愤怒、希望。

试着给它一个具体的东西：一间亮着灯但没人回来的屋子、一壶烧开的水、冬天早上窗上的霜。

**比喻不是装饰，是另一种思考方式。**
