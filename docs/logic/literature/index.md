# 📖 文学赏析

> 灵犀馆 · 语言与逻辑魔法

文学赏析不是猜标准答案，而是回答一个问题：作者为什么要这样写，而不是那样写。
一句诗换一个词，意思就全变了——这门主题训练的就是这种敏感。

## 会聊到的问题

- 同一首诗，为什么不同的人读出不同的意思？
- 小说里的「我」和作者是同一个人吗？
- 为什么有些句子读起来就是好听？
- 经典凭什么经典？

## 学习方式

- **朗读**：声音能暴露你忽略的节奏和情绪。
- **改写对比**：把原句改一个词，看看效果差多少。
- **先感受，再分析**：说不出哪里好，往往是真的没被打动。

## 准备

- 一支笔：在书上划线、写批注，比保持干净有用
- 一个摘抄本，只抄真正让你停下来的句子
