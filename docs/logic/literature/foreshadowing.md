# 伏笔：为什么回头才看懂

🔍 读到最后，你「啊」了一声。

回头翻，发现答案早就写在那儿了。

**但当时你完全没看见。**

## 伏笔是什么

在结局之前，作者埋下的线索。

它有两个要求：

1. **当时看着自然**（不像刻意安排的）
2. **回头看时精确**（每个字都对得上）

**只满足第一条，是闲聊；只满足第二条，是剧透。**

## 三种常见埋法

**1. 物件**

一件反复出现的物品，最后成了关键证据。

**2. 习惯**

一个人总是做某个小动作——最后你才知道为什么。

**3. 一句「随口说的话」**

「我妈从来不让我进那个房间。」

**读者以为是背景，其实那是线索。**

## 为什么第一次读不到

因为你不知道**该注意什么**。

信息全都在，但你把它当成「气氛」而不是「线索」。

**这正是伏笔的魅力：它不骗你，只是没提醒你。**

## 一个练习

读第二遍时，标记出所有「第一次读时觉得多余」的句子。

**它们往往就是伏笔。**
