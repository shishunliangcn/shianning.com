# 谁在讲故事

🎭 同一件事：

- 「他推了我一把。」
- 「我拉了他一下。」

**两个版本，两个真相。**

## 三种常见视角

**1. 第一人称（「我」）**

- 你只知道「我」知道的事
- 容易被「我」带偏
- 好处：亲近、可信、有局限才有悬念

**2. 第三人称（「他」）**

- 可以写很多人的内心
- 视野广，但距离远
- 好处：能看到全貌和反讽

**3. 全知视角**

- 什么都知道，连结局都知道
- 像上帝在讲
- 好处：能评论、能暗示

## 视角为什么会「骗」你

第一人称的叙述者，可能是：

- 一个孩子（理解不完整）
- 一个骗子（故意误导）
- 一个病人（记忆有偏差）

**作者让你相信他——然后你会发现他不可靠。**

这叫「不可靠叙述者」，是很高级的写法。

## 一个练习

读一段故事，问：

> **叙述者知道什么？他不知道什么？他为什么想让我相信他？**

**答案往往就是作者真正想说的东西。**
