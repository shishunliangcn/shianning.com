# 为什么你停不下来

📱 说好只看五分钟。

一抬头，四十分钟过去了。

你有点懊恼：怎么又这样。

## 先别怪自己

你面对的，不是「一个 App」，而是一整个团队的工作成果。

他们的目标很明确：**让你多待一会儿。**

所以这不是一场公平的较量——你靠意志力，他们靠数据、A/B 测试和上亿次实验。

## 三个让你停不下来的机制

**1. 不知道下一条是什么**

如果每次刷到的内容都一样好，你很快就腻了。

所以算法要**时好时坏**：大部分一般，偶尔来一条特别对胃口的。

这种「不确定的奖励」，是老虎机的原理——**它比稳定的奖励更让人上瘾。**

**2. 永远没有「到底了」**

书有最后一页，剧有片尾曲。

但信息流没有终点。手指一划，永远有下一条。

**没有结束信号，你就不知道该在什么时候停。**

**3. 它会学习你**

你多看了一眼什么、在哪停了几秒、什么时候划走——都被记下来。

下一次，它给你的会更准。

**它在慢慢变成「最懂怎么留住你」的东西。**

## 怎么拿回一点控制

不用卸载，也不用彻底戒掉。几件小事就有效：

1. **关掉自动播放**：让「继续」需要你主动点一下。
2. **给时间设边界**：不是「看一会儿」，而是「看三个视频」——有明确终点。
3. **注意身体信号**：看完之后是更精神，还是更空？把这件事记下来。
4. **把手机放在另一个房间**：写作业的时候，物理距离比意志力可靠。
5. **主动搜索，而不是被动刷**：带着目的去，比被推着走要好得多。

## 一个判断标准

不是「用了多久」，而是：

> **关掉之后，你感觉怎么样？**

- 学到了一点东西、跟朋友聊得开心 → 值。
- 空虚、烦躁、觉得刚才那一小时不知道去哪了 → 这个信号，要听。
