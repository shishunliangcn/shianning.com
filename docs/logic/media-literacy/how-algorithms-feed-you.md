# 算法怎么决定你看到什么

🎯 你刷到的每一条内容，都是被「算」出来的。

不是因为它最好，而是因为**它最可能让你留下来。**

## 它看的是什么

推荐系统不读内容，它读**行为**：

- 你看了多久（完播率）
- 你有没有点赞、评论、转发
- 你划走了多快
- 和你相似的人看了什么

**它对「内容」没有判断力，只对「反应」敏感。**

## 三个后果

**1. 你会越来越窄**

系统发现你喜欢 A，就一直给你 A。

**你看到的「世界」，慢慢只剩下一个人口味的切片。**

这叫「信息茧房」，但更准确的说法是：**它把你的一部分兴趣，当成了你的全部。**

**2. 情绪化的内容更容易被推**

愤怒、惊讶、感动——这些能让人停留、评论、转发。

**平淡但重要的内容，天然吃亏。**

**3. 它会「试探」你**

系统会不断拿新东西试你。

所以你的口味不是「被发现」的，是**被一点点塑造出来的**。

## 怎么拿回一点主动权

- **主动搜索**，而不是只被动刷
- 刻意去看**和你观点不同**的内容
- 定期清一次「推荐偏好」
- 注意：**你最近在看什么，决定了你接下来看到什么**

## 一个判断

关掉 App 之后，问自己：

> **刚才那半小时，是我在选内容，还是内容在选我？**
