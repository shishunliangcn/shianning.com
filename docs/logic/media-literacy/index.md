# 📱 媒介素养

> 灵犀馆 · 语言与逻辑魔法

我们每天泡在信息里，却很少有人教怎么「吃」它。
这个主题练三件事：判断真假、识别套路、管住自己的注意力。

## 会聊到的问题

- 一条消息看起来很真，怎么验证它不是假的？
- 为什么短视频一刷就停不下来？
- 广告和内容的边界在哪？
- 转发之前，应该先问自己什么？
- 屏幕时间该怎么定，才不是大人单方面下令？

## 三个可以马上用的动作

1. **停三秒**：看到让自己生气或激动的消息，先别转。
2. **找源头**：这句话最早是谁说的？有没有原始出处？
3. **看动机**：这条内容想让谁获益？

## 给家长

完全禁止屏幕，通常只会让使用变得更隐蔽。
更现实的目标是：一起看、一起聊、一起定规则，并允许规则被讨论。
