# 标题为什么总在骗你

📰 「震惊！原来一直都用错了。」

点进去，发现是「牙膏要从底部挤」。

**标题和内容之间，隔了一整个情绪。**

## 常见套路

**1. 制造信息缺口**

「他只说了一句话，全场安静。」

**不告诉你是什么，让你必须点进去补全。**

**2. 制造焦虑**

「再不看就晚了」「这种食物正在毁掉你的健康」。

**3. 数字与权威**

「90% 的人都不知道」「医生从不告诉你」。

**90% 这个数字，通常没有来源。**

**4. 反常识**

「每天喝八杯水是错的」。

**反常识不等于错，但它天然吸引点击——所以最容易被滥用。**

## 为什么标题会变成这样

因为**点击率是唯一被测量的东西**。

编辑不看你读完了没有，只看你点没点。

**当指标只有点击，标题就会往「骗点击」的方向进化。**

## 一个自保的习惯

看到情绪强烈的标题，先做一件事：

> **问：它想让我知道什么？还是想让我点什么？**

如果一句话就能说清事实，而标题偏偏不说——**那多半是在钓你。**

## 反过来

好的标题也会「留钩子」，但它不骗人。

区别在于：**点进去之后，你得到的东西对得起那个标题。**
