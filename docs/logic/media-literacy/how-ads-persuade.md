# 广告是怎么说服你的

📺 一支广告：一个孩子喝了某牌牛奶，跑步得了第一。

它从头到尾没说一句「我们的牛奶有营养」。

## 广告在做三件事

**1. 制造一个缺口**

它先让你觉得「现在的你不够好」——不够快、不够酷、不够受欢迎。

然后给你一个解决办法：买这个。

**「满足需求」之前，先「制造需求」。**

**2. 借用一个感觉**

把产品和某种情绪绑在一起：快乐、自由、被爱、成功。

你记住的不是产品参数，是那种感觉。

**3. 用别人的样子说服你**

广告里的人，总是朋友很多、笑容很亮。

它不跟你说道理，它让你**想成为那个人**。

## 三个可以问的问题

看到任何广告，问：

1. **它在让我觉得自己缺什么？**
2. **如果去掉背景音乐和笑容，它还剩什么信息？**
3. **买完之后，那种感觉能持续多久？**

## 一个更高的层次

广告不只看「卖什么」，也看**它在暗示什么价值观**。

「用了这个，你才是好妈妈」——这句话比产品本身更值得警惕。
