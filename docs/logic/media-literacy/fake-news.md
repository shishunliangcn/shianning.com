# 这条消息是真的吗

📱 群里有人转发：「某地发生了……」「专家说……」

配了截图，看着很真。

## 四个动作

**1. 找源头**

这条消息最早是谁发的？

- 有具体机构、姓名、时间吗？
- 还是「据说」「网友爆料」？

**没有源头的信息，等于没有信息。**

**2. 看有没有第二家**

一件真事，通常不会只有一个小号在说。

**如果主流媒体都没有报道，先别转。**

**3. 截图和视频最容易造假**

- 截图可以 P
- 视频可以剪辑、可以配上无关的旁白
- **旧视频换个标题，就成了「今天发生」**

可以试：把视频里的关键画面截下来，做反向图片搜索。

**4. 注意它想让你干什么**

「快转发，让更多人知道」「不转不是中国人」。

**要求你「立刻传播」的，往往最不希望你核实。**

## 一个容易被忽略的

**「有专家说」不等于有专家。**

专家是谁？哪个机构？他说的是原话吗？

**很多时候，是「某个人说的话」被剪成「专家说」。**

## 最有用的一条

**转发之前，先等十分钟。**

十分钟里，通常会有第一轮辟谣出现。

**你不是必须第一时间表态。**
