# 英语里没有「您」

🗣️ 中文里，「你」和「您」是两个词。

英语里只有一个 **you**。

对朋友、对老师、对国王，都是 you。

## 曾经不是这样

古英语里也有区分：

- **thou**：你（亲近、单数）
- **you**：您（尊敬、复数）

和中文的「你／您」几乎一样。

## 为什么 thou 消失了

几个原因叠在一起：

**1. 社交上「保险」**

跟人说话用 you 不会失礼，用 thou 却可能冒犯（等于把对方当「下人」）。

**大家都选了安全的那个。**

**2. 宗教与出版的影响**

《圣经》英译本的普及，让 you 的使用场景进一步扩大。

**3. 语言的自然简化**

英语丢掉了很多屈折变化（词尾变化），thou 配套的动词形式（thou art、thou hast）也跟着消失。

## 结果

**英语失去了「敬语」这一整层。**

所以英美人表达尊敬，不靠代词，靠：

- 加 please / thank you
- 用更完整的句子
- 语气和场合

**「简单」不等于「没有礼貌」，只是礼貌放到了别的地方。**

## 一个对照

日语、韩语有复杂的敬语系统；中文有「你／您」；英语几乎没有。

**每种语言都在某些地方「精细」，在另一些地方「粗糙」。**
