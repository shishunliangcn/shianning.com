# 🔤 趣味英语

> 灵犀馆 · 语言与逻辑魔法

这里不讲语法填空，专挑那些「原来如此」的瞬间：
为什么这个词是这个意思？为什么外国人这么说？为什么发音和拼写差这么远？

## 从这里开始

- [为什么英语里的 I 永远大写](/logic/english-fun/why-i-capital)

## 会聊到的问题

- 英语里为什么有这么多不发音的字母？
- 同一个词，为什么英国人和美国人用法不同？
- 习语背后的故事是什么？
- 中文和英语的思维方式差在哪？

## 学习方式

- **查词源**：一个词的历史，往往比它的释义有趣。
- **听原声**：发音靠模仿，不靠音标。
- **把单词放进句子**：孤立背的单词，用的时候想不起来。
