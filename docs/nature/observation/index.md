# 🌿 自然观察

> 格物馆 · 探索宇宙与自然

观察是可以练的。同一棵树，看十分钟和看一眼，得到的东西完全不同。
这个主题不急着讲知识，先练「看见」：形状、颜色、变化、差异。

## 会聊到的问题

- 蚂蚁搬食物时，是怎么找到路的？
- 叶子为什么会变黄？为什么有的树不落叶？
- 鸟叫是在说什么？
- 楼下的树，一年里会经历哪几个阶段？

## 怎么开始

- **每周一次户外**：固定的地点比新地方更好，因为能看出变化。
- **带三样东西**：放大镜、小本子、一支笔。
- **只记一个问题**：不要贪多，一次观察只回答一个问题。

## 给家长

孩子蹲在路边看蚂蚁，不是浪费时间，那正是他的实验室。
你只需要做一件事：别催他。
