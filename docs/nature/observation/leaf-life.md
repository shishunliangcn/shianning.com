# 一片叶子的一生

🍃 春天，树尖上冒出一个卷着的小芽。

夏天，它宽大、深绿，在风里翻面。

秋天，它变黄、变红，然后落下。

冬天，它不见了。

## 绿叶在干什么

叶子里有一种绿色的东西，叫**叶绿素**。

它能把阳光、水和空气，变成糖——**这就是植物的饭**。

这个过程叫光合作用。树不需要吃饭，它自己做饭。

## 为什么秋天会变黄

秋天光照变短、变冷，叶子「不划算」了。

树开始回收：把叶子里的养分抽回枝干，然后切断给叶子的水和养料。

叶绿素先分解——绿色退去，藏在下面的**黄色、橙色**就露出来了。

有些叶子变红，是因为新的色素（花青素）在低温下生成。

**所以秋天的颜色，是「卸妆」之后露出来的底色。**

## 落叶之后

叶子落到地上，被虫子和微生物分解，变成养分回到土里。

**树吸收了它，明年再长出新叶。**

一块叶子从来没有「消失」，它只是换了一种形态，继续参与。
