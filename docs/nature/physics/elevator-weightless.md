# 电梯启动时，为什么觉得变轻了

🛗 电梯往上启动的一瞬间，胃里一空。

往下启动时，脚底一沉。

**你的体重一直没变。**

## 你感觉到的不是重力

是**支持力**——地板推你的力。

- 站在地上，地板托着你，支持力 = 重力，你「觉得正常」。
- 电梯向上加速，地板要**多推你一点**——你觉得「变重」。
- 电梯向下加速，地板**推得少一点**——你觉得「变轻」。

**身体感觉到的，是「被托住的力」，不是重力本身。**

## 自由落体的电梯

如果电梯的缆绳断了（这只是思想实验），电梯和你一起下落。

**地板不再推你。**

支持力 = 0——你「飘」起来了。

**这叫「失重」。**

## 一个反直觉的点

**失重不等于没有重力。**

在空间站里，宇航员感受到的正是这种感觉：**他们其实一直在「往下掉」**，只是横向速度太快，一直掉不到地上。

**那是「自由落体」，不是「没有引力」。**

## 一个能做的观察

坐电梯时，注意三个时刻：

1. 启动瞬间（变重或变轻）
2. 匀速时（恢复正常）
3. 停下瞬间（相反的感觉）

**你的身体，是一台很灵敏的加速度计。**
