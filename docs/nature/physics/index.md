# ⚛️ 物理

> 格物馆 · 探索宇宙与自然

物理的野心是：用最少的规律解释最多的现象。
从苹果落地到卫星入轨，用的是同一套语言。

## 会聊到的问题

- 力到底是什么？为什么推一下东西它才动？
- 能量守恒意味着永动机不可能吗？
- 电和磁为什么是一回事？
- 时间真的会变慢吗？

## 学习方式

- **先画图**：受力图、光路图、电路图，图对了题就成了一半。
- **量纲检查**：单位对不上，思路一定错了。
- **做实验**：哪怕只是用手机测加速度，也比看视频强。

## 准备

- 一个卷尺、一个秒表（手机即可）、一个弹簧秤
- 愿意把「我觉得」改成「我测到」
