# 声音是怎么跑到你耳朵里的

🔊 敲一下桌子。

你听见「咚」——但那声音不是「从桌子上飞出来」的。

## 声音是振动

物体振动，会推动旁边的空气。

空气被挤压、松开，再挤压——**这种疏密的变化，一层层传出去。**

传到你的耳朵，让鼓膜振动，你就听见了。

**声音不是物质，是一种「波」。**

## 它在不同的东西里跑得不一样快

| 介质 | 速度（大约） |
| --- | --- |
| 空气 | 340 米/秒 |
| 水 | 1500 米/秒 |
| 钢铁 | 5000 米/秒 |

**越「密」的东西，传得越快。**

所以趴在铁轨上能提前听到远处的火车。

## 真空里没有声音

因为没有东西可以振动。

太空里发生爆炸，你是听不见的。

（电影里的爆炸声，是给观众配的音效。）

## 一个能做的观察

把耳朵贴在桌面上，用手指轻轻敲桌子另一端。

再把耳朵抬起来敲一次。

**贴着桌面听到的更响、更清楚**——因为固体传声效率更高。
