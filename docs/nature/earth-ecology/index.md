# 🌍 地球与生态

> 格物馆 · 探索宇宙与自然

地球是一台仍在运转的机器：板块在挪动，大气在循环，生命在互相供养。
这门主题关心的是「系统」——牵一发，动全身。

## 会聊到的问题

- 山是怎么长出来的，又为什么会矮下去？
- 为什么沿海多雨、内陆干燥？
- 一个物种消失，会带走什么？
- 气候变化到底改变了什么？

## 学习方式

- **看图**：地质图、气候图、生态金字塔，读图比背书有效。
- **用身边的例子**：本地的河、山、天气记录，就是最好的样本。
- **建立尺度感**：一米、一公里、一万年，都是不同的时间与空间尺度。

## 准备

- 一张本地地形图
- 一个记录天气的小本子（连续记一个月，你会看到规律）
