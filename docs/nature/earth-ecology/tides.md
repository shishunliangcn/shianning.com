# 海水一天涨两次，是谁在拉它

🌊 海边的水，一天涨两次、退两次。

没有人推它，也没有人抽它。

## 是月亮在拉

月亮对地球有引力。

地球朝着月亮的那一面，海水被拉起来——形成一个「鼓包」。

背对月亮的那一面，也会鼓起来（因为地球整体被拉向月亮，背面的水「落后」了）。

**所以地球上同时有两个高潮区。**

地球每天自转一圈，一个地方会先后经过这两个鼓包——**一天两次高潮、两次低潮。**

## 太阳也在拉

太阳离得远，但质量大，引力也不小——大约是月亮的一半。

当太阳、月亮、地球排成一线（农历初一、十五），两者叠加，潮差最大，叫**大潮**。

当它们成直角（上弦、下弦），互相抵消，潮差最小，叫**小潮**。

## 一个可以观察的事

如果你去海边，记一下涨潮时间。

第二天，你会发现涨潮晚了大约 **50 分钟**。

因为月亮绕地球转，每天「迟到」约 50 分钟。
