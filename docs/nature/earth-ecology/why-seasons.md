# 为什么会有四季

🌍 很多人以为：夏天是因为地球离太阳近。

**不是。**

## 真正的答案：地轴是斜的

地球自转的轴，和公转平面有大约 **23.5°** 的夹角。

所以地球绕太阳转的时候，不同半球被阳光「照」的角度不一样：

- 北半球倾向太阳 → 阳光更直、白天更长 → **夏天**
- 北半球背离太阳 → 阳光更斜、白天更短 → **冬天**

**决定冷热的不是距离，是阳光照射的角度。**

## 一个反直觉的事实

地球离太阳**最近**的时候，是北半球的**冬天**（一月初）。

离得近反而冷——这正好说明，距离不是主因。

## 为什么赤道没有四季

赤道那里，全年阳光角度都差不多。

所以没有明显的四季，只有旱季和雨季。

## 为什么两极有极昼极夜

因为地轴倾斜，夏天时北极一直朝着太阳，转一圈也晒得到——太阳不落。

冬天则相反，太阳一直不升起。
