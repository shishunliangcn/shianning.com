# 水去哪儿了

💧 一杯水放在桌上，几天后没了。

它没有消失，它进了空气里。

## 水循环

```
蒸发 → 成云 → 降水 → 汇入河流 / 渗入地下 → 再蒸发
```

**同一批水，一直在转圈。**

## 几个环节

**蒸发**：太阳加热水面，水变成水蒸气升上去。

**凝结**：高空温度低，水蒸气变回小水滴，聚成云。

**降水**：水滴大了，落下来（雨、雪）。

**径流**：落到地面的水，一部分流进河湖，一部分渗进地下。

**地下也有水**——含水层，很多地方的自来水就从那里抽。

## 一个有点震撼的事实

**地球上的水总量，几十亿年基本没变。**

所以你今天喝的这杯水，可能被恐龙喝过、被古人用过，**只是换了形态。**

## 但「有水」不等于「有能喝的水」

- 海水占 97%，不能直接喝
- 淡水大部分锁在冰川里
- **真正容易用的淡水，不到总量的 1%**

**所以「节约用水」不是口号，是在说：可用的那部分很少。**
