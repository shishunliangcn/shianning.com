# 🌌 格物馆

> 探索宇宙与自然

“格物”是古人说的「推究事物的道理」。
这里不谈年级，只谈问题：星星为什么会发光？水为什么会结冰？山是怎么长出来的？

## 这座展馆有什么

| 主题 | 聊什么 |
| --- | --- |
| [🔭 天文](/nature/astronomy/) | 恒星、行星、星系，以及人类如何量出宇宙 |
| [⚛️ 物理](/nature/physics/) | 力、能量、电磁与时空 |
| [🧪 化学](/nature/chemistry/) | 原子如何结合，物质为什么有脾气 |

## 怎么逛这座馆

1. **从现象出发**：先问「为什么」，再找规律，最后才记公式。
2. **动手胜过看图**：能做的实验就做一遍，哪怕只是烧一壶水。
3. **允许不懂**：这里的很多问题，人类至今也没有完全答案。
