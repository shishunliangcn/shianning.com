# 会开花的纸

🌸 剪一朵纸花，把花瓣往中间折起来。

放到水面上。

几秒钟，花瓣自己张开了。

## 一、水在往纸里爬

纸是由植物纤维压成的，纤维之间有无数细小的缝隙。

水会沿着这些缝隙**往上爬**——这叫**毛细现象**。

**原因是「表面张力」加「附着力」：**

- 水分子之间互相拉（表面张力）
- 水分子也拉着纸纤维（附着力）
- 当附着力够强，水就顺着缝隙往上走

**水不是被推上去的，是被「拉」上去的。**

## 二、为什么花瓣会张开

纸吸了水，纤维**膨胀**。

折痕处的纤维一旦变厚，折角就撑开了。

**所以不是水推开花瓣，是纸自己在「长胖」。**

## 三、动手做

1. 在纸上画一朵花，花瓣 6–8 片。
2. 剪下来。
3. **每片花瓣沿根部向中心折起**（折得整齐，开得才好看）。
4. 轻轻放在水面上，花瓣朝上。

**用不同厚度的纸各做一朵**，比一比谁开得快：

- 越薄、越吸水 → 越快
- 表面涂过蜡或油 → 几乎不开

## 四、现实里的它

- **毛巾吸水**、纸巾吸水
- **蜡烛的棉芯**把蜡油吸到火焰处
- **植物的根**把水运到叶子
- **砖墙「返潮」**：地下水沿缝隙爬上来

**都是同一种「往上爬」。**

## 五、一个可以继续问的

**为什么水能爬上去，却不掉下来？**

因为缝隙很细，水的表面张力能「挂住」——**管子越细，爬得越高。**

（这是「毛细管」的规律。）
