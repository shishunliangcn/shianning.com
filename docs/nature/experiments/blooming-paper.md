# 会开花的纸

🌸 剪一朵纸花，把花瓣往中间折起来。

放到水面上。

几秒钟，花瓣自己张开了。

## 为什么

纸是由纤维压成的，中间有无数细小的缝隙。

水会沿着这些缝隙**往上爬**——这叫**毛细现象**。

水爬进折痕里，纤维吸水膨胀，花瓣就被「撑」开了。

**不是水推它，是纸自己在喝水。**

## 怎么做

1. 在纸上画一朵花，剪下来（花瓣 6–8 片）。
2. 每片花瓣向中心折起。
3. 轻轻放在水面上，花瓣朝上。
4. 数秒，看它慢慢张开。

**用不同厚度的纸各做一朵**，比一比谁开得快。

越薄、越吸水，开得越快。

## 生活里的它

- 毛巾吸水、纸巾吸水
- 蜡烛的棉芯把蜡油吸上来
- 植物把水从根运到叶子

**都是同一种「往上爬」。**
