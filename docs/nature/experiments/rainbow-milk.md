# 彩虹牛奶

🥛 盘子里倒一层牛奶，滴几种色素。

用棉签蘸一点洗洁精，轻轻点在中间。

颜色「砰」地散开，像一朵花。

## 为什么

牛奶表面有一层**表面张力**——水分子互相拉着，形成一层「膜」。

洗洁精是**表面活性剂**，它会插进这层膜里，把张力破坏掉。

张力一破，牛奶表面开始流动，颜色被带着跑。

**你看到的不是「爆炸」，是液体的流动。**

## 怎么做

1. 浅盘里倒牛奶（没过盘底）。
2. 滴 3–5 滴不同颜色的食用色素，别搅。
3. 棉签蘸洗洁精，点在色素中央。
4. 想再来一次：换一根新棉签（旧的已经沾满洗洁精）。

## 延伸

这也是洗洁精能洗碗的原理：**破坏油污的表面张力，让油被水带走。**

用油和水做同样的实验，效果更明显——因为油本来就不溶于水。

## 注意

实验用的牛奶不要喝。
