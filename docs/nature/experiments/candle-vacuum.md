# 蜡烛把水吸进了杯子

🕯️ 盘子里倒一点水，中间立一支点燃的蜡烛，把玻璃杯倒扣上去。

火灭了。

然后水开始往杯子里爬。

## 为什么

燃烧需要氧气。

杯子里那点氧气被烧光，火就灭了。

**氧气没了，杯子里的气体总量变少，压力变低。**

外面的大气压没变，就把盘子里的水压进了杯子。

**所以不是「吸」，是「压」。**

## 怎么做

1. 盘子加水（滴两滴色素更清楚）。
2. 中间放一支矮蜡烛，点燃。
3. 玻璃杯倒扣，罩住蜡烛。
4. 看水位上升多少。

## 一个可以继续问的问题

**水会升到多高？**

如果杯子越大、氧气越多，理论上应该吸得越多——但实际实验里，水通常升不到杯子的一成。

为什么？因为燃烧还产生了二氧化碳，它补上了一部分减少的体积。

**这就是「做实验比背结论有意思」的地方。**

## 安全

- 蜡烛要矮，别让杯口烫到手。
- 大人在场，头发扎起来。
- 做完等杯子冷却再拿。
