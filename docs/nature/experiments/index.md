# ⚗️ 趣味实验

> 格物馆 · 探索宇宙与自然

实验的目的不是「做出漂亮的结果」，而是验证一个猜想。
这里的实验都能用厨房里的材料完成，重点在过程，不在成品。

## 会聊到的问题

- 盐放进水里去哪了？
- 为什么有的东西会浮，有的会沉？
- 小苏打加白醋，为什么会冒泡？
- 影子为什么早上长、中午短？

## 一次实验的五个步骤

1. **提问**：我想知道什么？
2. **猜想**：我猜会怎样（先写下来）。
3. **动手**：一次只改一个条件。
4. **记录**：画下来，或者写数字。
5. **解释**：结果和猜想一样吗？为什么？

## 安全提示

- 涉及热水、明火、尖锐物的实验，必须有大人全程在场。
- 任何东西都不入口，实验后洗手。
