# 头发能把纸吸起来

🎈 气球在头发上蹭十几下，靠近碎纸屑。

纸屑跳起来，粘在气球上。

## 一、摩擦做了什么

物质由原子组成，原子中间是带正电的原子核，外面是带负电的电子。

**正常情况下，正负电荷一样多，所以不带电。**

摩擦会让**电子从一个物体跑到另一个物体**：

- 气球抢走了头发上的一些电子 → **气球带负电**
- 头发失去了电子 → **带正电**

**所以摩擦不是「产生电」，是「搬运电荷」。**

## 二、为什么纸屑会被吸

纸屑本来不带电。

但当带负电的气球靠近时，纸屑内部的电荷会重新排列——**靠近气球的一面变正，远离的一面变负。**

**异性相吸**，纸屑就被拉过去了。

**这叫「静电感应」。**

## 三、动手做

1. 把纸撕成很小的碎屑（越小越明显）。
2. 气球在头发或毛衣上快速摩擦 10–20 秒。
3. 慢慢靠近纸屑——**不要碰到**。
4. 试试靠近细细的水流（水龙头开到最细），看水流会不会弯。

## 四、为什么过一会儿就不吸了

电荷会慢慢「跑掉」——通过空气里的水汽、通过你的手、通过桌面。

**这叫放电。**

所以：

- **冬天更容易成功**（空气干燥，电荷不容易跑）
- **夏天常失败**（湿度高，电荷很快被导走）

## 五、现实里的它

- **闪电**：云层里积累的电荷，最终击穿空气
- **复印机 / 激光打印机**：用静电吸附墨粉
- **静电除尘**：工厂用静电吸附烟尘
- **冬天开门被电一下**：你和门把手之间的放电

## 六、安全提醒

**家用电（220V）和静电完全不是一回事。**

静电的电压可能上万伏，但电量极小，只会「麻一下」。

**家用电会致命——这是两个概念，不要混淆。**
