# 头发能把纸吸起来

🎈 气球在头发上蹭十几下，靠近碎纸屑。

纸屑跳起来，粘在气球上。

## 为什么

摩擦让气球表面带上了**静电**。

带电的物体靠近轻小的东西（纸屑），会让纸屑内部电荷重新排列，靠近气球的一面带上相反的电荷。

**异性相吸**，纸屑就被拉过去了。

## 怎么做

1. 把纸撕成很小的碎屑。
2. 气球在头发或毛衣上快速摩擦 10–20 秒。
3. 靠近纸屑——不要碰到。
4. 也可以靠近细细的水流（水龙头开到最细），看水流会不会弯。

## 为什么会消失

过一会儿就不吸了。

因为电荷慢慢「跑掉」了——通过空气、通过你的手。这叫**放电**。

冬天更容易做成：空气干燥，电荷不容易跑。
