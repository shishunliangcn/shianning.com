# 分层饮料：一个杯子里的三层

🥃 一个透明杯子，先倒蜂蜜，再慢慢倒水，最后倒油。

三层，清清楚楚，分界像画出来的。

## 为什么

**密度不同。**

同样体积，蜂蜜比水重，水比油重。

重的东西在下面，轻的在上面——只要它们不相溶（油和水不相溶），就会一直分层。

## 怎么做

1. 先倒蜂蜜（最重），铺满杯底。
2. 沿着杯壁慢慢倒水，别冲散。
3. 最后沿杯壁倒油。
4. 放一颗葡萄、一颗花生、一颗樱桃进去，看它们停在哪一层。

**它们会停在和自己密度相近的层。**

## 注意

这是实验，不是饮料，不要喝。

油和洗洁精能「乳化」——加一滴洗洁精再搅，三层会变浑浊，这就是洗碗的原理。
