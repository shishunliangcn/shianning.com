# 一张纸能承多重

📄 一张 A4 纸，架在两摞书之间，中间放一枚硬币——塌了。

把它折成瓦楞形（像连续的「W」），再试一次。

这次能放十几本。

## 为什么

平铺的纸很薄，受力时只能靠「抗弯」——而它的厚度几乎为零，所以一压就弯。

折成瓦楞之后，纸有了**高度**。力被分散到一条条竖着的「墙」上，这些墙能承受压力。

**同样的材料，换个形状，强度差几十倍。**

## 怎么做

1. 把纸裁成长条，来回折成 W 形。
2. 把折好的纸条竖着排在两摞书之间。
3. 上面放一本薄书，再放一本，一直加。
4. 记下最多能放几本。

## 现实里的它

瓦楞纸箱、飞机的加强筋、桥梁的桁架——都是同一个道理。

**工程师不是找更强的材料，而是把材料放在更聪明的位置。**
