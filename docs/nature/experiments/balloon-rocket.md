# 气球火箭

🎈 把线穿过吸管，两端固定。气球吹好，粘在吸管上，松手。

气球「嗖」地冲出去。

## 为什么

气球里的空气向后喷出，气球就向前跑。

这叫**反作用力**：你推空气，空气也推你。

真正的火箭一样——向后喷燃料，向前飞。

## 怎么做

1. 一根细线（或鱼线）拉直，两端系在椅子背上。
2. 吸管穿在线上。
3. 气球吹大，捏住口，用胶带粘在吸管上。
4. 松手。

## 试试改变条件

- **气球吹大一点** → 飞得更远吗？
- **线拉紧一点** → 更快吗？
- **把吸管换成两个** → 会变慢（摩擦变大）。

**一次只改一个条件**，你就在做真正的实验。
