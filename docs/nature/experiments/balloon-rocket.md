# 气球火箭

🎈 把线穿过吸管，两端固定。气球吹好，粘在吸管上，松手。

气球「嗖」地冲出去。

## 一、它为什么往前走

气球里的空气向后喷，气球就向前跑。

**这叫反作用力：你推空气，空气也推你。**

这不是「气球想往前」，而是**它必须往前**——因为空气被推走了，总得有个东西承担这个力。

**真正的火箭一样：向后喷燃料，向前飞。**

## 二、一个关键：它不是在「飞」

火箭和气球都在做同一件事：**扔东西**。

- 火箭扔的是燃烧后的气体
- 气球扔的是里面的空气

**扔得越快、越多，自己被推得越快。**

所以在太空里，火箭不需要「踩空气」也能前进——**它推的是自己的燃料，不是地面。**

## 三、动手做

**材料**：一根细线（或鱼线）、一段吸管、一个气球、胶带。

1. 线拉直，两端系在椅子背上。
2. 吸管穿在线上。
3. 气球吹大，捏住口，用胶带粘在吸管上（**胶带贴气球侧面，别贴在吹口**）。
4. 松手。

## 四、像科学家一样改条件

一次只改一样，记录每次的距离：

| 改什么 | 猜猜会怎样 |
| --- | --- |
| 气球吹大一点 | 飞得更远？ |
| 线拉紧一点 | 更快？ |
| 换更粗的吸管 | 摩擦变大，变慢？ |
| 气球上挂一个小重物 | 变慢，还是更稳？ |

**「猜—试—记」这三步，就是实验。**

## 五、常见误解

**「气球是被空气推着走的。」**

不是。**是气球把空气推出去，自己反被推。**

如果把气球放在真空里（理论上），它照样能飞——因为没有空气阻力。

**「飞得远说明气球好。」**

不一定。距离受气球大小、线的松紧、摩擦影响。

**变量太多时，结论就不靠谱。**

## 六、现实里的它

- **火箭**：同样的原理，只是燃料更猛
- **喷气飞机**：向后喷气
- **水火箭**：用水的反冲
- **鱿鱼**：喷水前进，也是反作用力

**从气球到火箭，中间只差「燃料有多猛」。**
