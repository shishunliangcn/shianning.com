# 柠檬也能发电

🍋 把一枚铜币、一枚锌片（或镀锌钉）插进柠檬，接上导线。

中间串一个小 LED。

它亮了——虽然很暗。

## 为什么

柠檬汁是**酸**，里面有可以移动的离子。

两种不同的金属插进去，会发生化学反应：一种金属失去电子，另一种得到电子。

**电子从一边跑到另一边，就形成了电流。**

这就是电池的原理：**两种不同的金属 + 一种电解质。**

## 怎么做

1. 柠檬揉一揉（让汁液流动），切开一个小口。
2. 插入铜币和锌钉，两者**不要碰到**。
3. 导线分别接在两片金属上，另一头接 LED 的两只脚。
4. 如果灯不亮，把 LED 的两脚对调——它有方向。

## 一个柠檬不够怎么办

**串联多个柠檬**：一个的铜接下一个的锌。

电压会叠加。

一般一个柠檬大约 0.9 伏，几个串起来才够点亮 LED。

## 家用的电池长什么样

干电池里是同样的结构：正极、负极、电解质，只是被做成了「干」的。

**你手里那个小小的电池，和柠檬是同一套逻辑。**
