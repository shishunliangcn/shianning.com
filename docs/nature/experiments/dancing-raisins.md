# 会跳舞的葡萄干

🥤 倒一杯汽水，丢几粒葡萄干进去。

它们先沉底，过一会儿浮上来，又沉下去。

一直跳。

## 为什么

汽水里溶着二氧化碳。

葡萄干表面粗糙，气泡容易附着在上面。

气泡越聚越多，像给葡萄干绑了一串气球——**浮力变大，就浮上去了。**

到了水面，气泡破掉，气球没了，它又沉下去。

**如此反复，看起来就像在跳舞。**

## 怎么做

1. 一杯汽水（刚开的，气泡多）。
2. 丢入 5–6 粒葡萄干。
3. 观察它们的「上下」周期，数一数一分钟能浮几次。

试试换成别的东西：米粒、小石子、通心粉——哪些会跳，哪些不会？为什么？

## 由此想到

鱼靠鱼鳔调节浮沉，潜水艇靠水舱。

**都是同一件事：改变自己的「平均密度」。**
