# 🧪 化学

> 格物馆 · 探索宇宙与自然

化学研究的是「原子怎么牵手，又怎么分开」。
它解释了为什么铁会生锈、面包会发起来、药能治病也能伤身。

## 会聊到的问题

- 元素周期表为什么长这样？
- 为什么有的反应放热，有的要加热才发生？
- 塑料、陶瓷、合金，差别在哪？
- 家里的清洁剂为什么不能混用？

## 学习方式

- **从厨房开始**：发酵、焦糖化、腌制，都是化学反应。
- **记结构，不背现象**：结构决定性质，性质决定用途。
- **安全第一**：不明物质不混合、不加热、不入口。

## 准备

- 一本元素周期表（贴在墙上比存在手机里有用）
- 小苏打、白醋、紫甘蓝汁，就能做酸碱指示剂
