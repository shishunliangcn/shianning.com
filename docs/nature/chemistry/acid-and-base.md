# 酸和碱，就在你家的厨房里

🍋 柠檬酸、醋是酸。

小苏打、肥皂水是碱。

**它们一见面，就会反应。**

## 怎么区分

**酸**：

- 尝起来酸（但实验室里绝不能尝）
- 能让蓝色石蕊试纸变红
- 常见的：醋、柠檬汁、可乐、胃酸

**碱**：

- 摸起来滑滑的（像肥皂水）
- 能让红色石蕊试纸变蓝
- 常见的：小苏打、肥皂、洗衣粉、石灰水

## 它们相遇会怎样

**中和。**

酸 + 碱 → 盐 + 水。

如果其中一种是碳酸盐（比如小苏打），还会放出**二氧化碳**——所以会冒泡。

## 一个能做的实验

1. 小半杯白醋。
2. 加一勺小苏打。
3. 立刻冒起大量泡沫。

**这就是酸碱中和 + 放出气体。**

## pH 值

用一个 0–14 的刻度表示酸碱度：

- 7 是中性（纯水）
- 小于 7 是酸
- 大于 7 是碱

**醋大约 3，柠檬 2，肥皂水 9–10，胃酸 1–2。**

## 为什么胃酸不把胃烧穿

胃壁有一层黏液保护。

但压力大、饮食乱的时候，保护会变弱——这就是胃溃疡的部分原因。

**身体里的化学，比厨房里的更精密。**
