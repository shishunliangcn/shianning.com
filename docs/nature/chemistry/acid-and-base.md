# 酸和碱，就在你家的厨房里

🍋 柠檬是酸的，肥皂是滑的。

**这是两种性质相反的东西。**

它们相遇，会发生一件事：**中和。**

## 一、怎么区分

**酸：**

- 尝起来酸（**但实验室里绝不能尝**）
- 能让蓝色石蕊试纸变红
- 常见：醋、柠檬汁、可乐、胃酸、酸奶

**碱：**

- 摸起来滑滑的（像肥皂水）
- 能让红色石蕊试纸变蓝
- 常见：小苏打、肥皂、洗衣粉、石灰水、胃药

**记住试纸的方向：酸红碱蓝。**

## 二、pH：一个 0 到 14 的刻度

| 物质 | pH |
| --- | --- |
| 胃酸 | 1–2 |
| 柠檬汁 | 2 |
| 醋 | 3 |
| 咖啡 | 5 |
| 纯水 | 7（中性） |
| 肥皂水 | 9–10 |
| 漂白水 | 12–13 |

**小于 7 是酸，大于 7 是碱，等于 7 是中性。**

注意：**pH 是「对数」刻度**——pH 3 比 pH 4 酸 10 倍，不是 1 倍。

## 三、它们相遇会怎样

**酸 + 碱 → 盐 + 水**

如果其中一种是碳酸盐（比如小苏打），还会放出**二氧化碳**。

**这就是你看到冒泡的原因。**

## 四、自己做一个指示剂

不用买试纸，紫甘蓝就能做。

1. 紫甘蓝切碎，用热水泡十分钟，滤出紫色的水。
2. 分成几杯。
3. 分别滴入：白醋、小苏打水、柠檬汁、清水、肥皂水。

**颜色会变：**

- 遇酸 → 偏红/粉
- 遇碱 → 偏蓝/绿
- 中性 → 保持紫色

**紫甘蓝里的花青素，就是天然指示剂。**

## 五、中和在生活里

- **胃药**：胃酸过多时，吃一点碱性药中和
- **土壤**：太酸的地撒石灰，太碱的地加有机肥
- **被蜜蜂蜇**：蜂毒偏酸（用肥皂水冲）；被马蜂蜇则相反
- **牙膏**：偏碱，中和口腔里的酸

## 六、为什么胃酸不会把胃烧穿

胃酸 pH 大约 1–2，强到能腐蚀金属。

**但胃壁有一层黏液，每几天更新一次。**

压力大、饮食乱、感染某些细菌时，这层保护会变弱——**这就是胃溃疡的部分原因。**

**身体里的化学，比厨房里的更精密，也更脆弱。**

## 七、安全提醒

- 强酸强碱都能灼伤皮肤和眼睛
- **稀释浓酸时，要把酸倒进水里，不能把水倒进酸里**（会剧烈放热、飞溅）
- 家用的洁厕灵和漂白水**不能混用**（会产生有毒气体）
