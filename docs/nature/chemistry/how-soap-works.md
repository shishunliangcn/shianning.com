# 肥皂为什么能洗掉油

🧼 手上沾了油，用水冲——冲不掉。

抹点肥皂，一搓，冲掉了。

## 油为什么冲不掉

**油和水不相溶。**

水分子之间互相吸引，抱成一团；油分子插不进去，只能浮在表面。

水流过时，只是从油上「滑过去」。

## 肥皂分子的秘密

肥皂分子长得很奇怪：

**一头是「亲水」的（喜欢水），另一头是「亲油」的（喜欢油）。**

放进水里，它们会自动排成一层——亲水那头朝水，亲油那头朝外。

## 它怎么把油带走

1. 亲油的那头**钻进油滴**里。
2. 亲水的那头留在外面，和水待在一起。
3. 油滴被一层肥皂分子包住，形成「胶束」。
4. **油滴被水「认作自己人」，跟着水一起冲走。**

**这就是「乳化」。**

## 为什么热水洗得更干净

温度高，油变稀、更容易被分散。

肥皂分子运动也更快。

**热水 + 肥皂，是最优组合。**

## 一个推论

洗碗时油太多，肥皂会「不够用」——每个油滴都要被包住才行。

**所以先刮掉大块油污，再洗，效果更好。**
