# 🔭 天文

> 格物馆 · 探索宇宙与自然

天文是最容易让人「愣住」的学科：你看到的星光，可能来自几百年前。
这里从肉眼可见的现象出发，一步步走到恒星的一生和宇宙的尺度。

## 会聊到的问题

- 恒星怎么诞生，又怎么死去？
- 为什么行星都绕着太阳转，而不是飞走？
- 宇宙到底有多大？我们怎么量出来的？
- 黑洞是什么？为什么说它「黑」？

## 需要什么

- 一双眼睛，和一个免费的星图 App（如 Stellarium Mobile）
- 双筒望远镜比初学者想象的更有用
- 一本能查到星等的纸质星图，停电时也能用
