# 月亮为什么会有圆缺

🌕 今天满月，隔一周变成半月，再隔一周只剩一弯。

**月亮本身没有变。**

## 关键：月亮自己不发光

它反射太阳的光。

**太阳永远只照亮月亮的一半。**

## 你看到的是什么

你站在地球上，看到的是「被照亮的那一半」中，朝向你的部分。

月亮绕地球转，**它和太阳、地球的相对位置一直在变**——所以你能看到的部分也在变。

## 一个月的变化

```
新月（看不见）→ 上弦月（右半）→ 满月 → 下弦月（左半）→ 新月
```

**周期约 29.5 天。**

## 一个能验证的方法

**连续一周，每天同一时间看月亮，画下形状。**

你会发现：

- 形状在渐变
- 位置每晚都在往东移动

**这就是它绕地球转的证据。**

## 一个常见误解

「月亮的影子是地球挡住的。」

**不对。** 那是月食，一年只有几次。

**日常的圆缺，是「我们看到的受光面在变」，不是地球挡光。**
