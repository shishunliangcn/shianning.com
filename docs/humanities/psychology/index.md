# 🧠 心理学

> 知音馆 · 穿梭历史与人文

心理学不是「猜别人在想什么」，而是用可验证的方法研究行为与心智。
这个主题从婴幼儿的情绪发育讲起，一路到青春期的脑与成人的认知偏差。

## 从这里开始

- [宝宝生气了，可以怎么做？](/humanities/psychology/baby-emotions) —— 2 岁情绪急救

## 会聊到的问题

- 2 岁宝宝的脾气是从哪来的？
- 依恋关系会如何影响一生？
- 青春期的大脑到底发生了什么？
- 我们为什么总在重复同样的选择？

## 学习方式

- **先观察，再解释**：从具体行为出发，别急着贴标签。
- **区分证据与故事**：流行的心理学说法，大多经不起重复验证。
- **用在自己身上**：理解自己，是理解孩子的起点。
