# 🏺 历史

> 知音馆 · 穿梭历史与人文

历史不是「哪年发生了什么事」，而是「他们当时有别的选择吗」。
这门主题关心两件事：事情怎么发生的，以及我们凭什么这么说。

## 会聊到的问题

- 文明为什么最早出现在大河流域？
- 帝国为什么会崩？是外敌还是内伤？
- 同一件事，胜利者和失败者的记录差在哪？
- 我们今天的选择，有哪些是被一百年前决定的？

## 学习方式

- **先搭时间轴，再填细节**：没有框架的知识记不住。
- **读一手材料**：奏折、日记、报纸，比教科书更接近现场。
- **区分事实与解释**：同一份史料，可以有不同解读。

## 准备

- 一张能贴墙上、可随时补充的时间轴
- 一个「疑问本」，专门记你还不理解的历史问题
