# 工业革命为什么先从英国开始

🏭 十八世纪，机器开始代替人力。

为什么是英国，不是法国、不是中国？

## 四样东西凑齐了

**1. 煤和铁，就在手边**

英国的煤田离地表近，容易挖；铁矿也不远。

**煤提供了能源，铁提供了材料。**

**2. 钱**

海外贸易和殖民让英国积累了资本。

有钱，才有人愿意投资「还不知道能不能成」的机器。

**3. 市场**

国内统一市场 + 海外殖民地。

**生产出来的东西，有地方卖。** 这是工厂能开下去的前提。

**4. 一种「试了再说」的环境**

专利制度保护发明者；工程传统浓厚；还有一批业余科学家和工匠互相串门。

**发明不是某个天才的灵光，是一群人在同一个圈子里互相抄、互相改。**

## 为什么不是中国

中国在宋代就有很先进的技术和手工业。

但缺少的是：**大规模的市场需求 + 能持续投资的资本 + 对私人发明的制度保护。**

技术领先，不等于工业革命。

**工业革命是「技术 + 制度 + 市场」三件事同时到位。**

## 一个观点

**历史很少由单一原因推动。**

看到「某某发明改变了世界」的说法时，多问一句：**为什么是这个时候、这个地方？**
