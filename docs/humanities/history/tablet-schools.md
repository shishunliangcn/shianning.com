# 五千年前的学校，在教什么

📚 两河流域出土过一批泥板，上面是学生的作业。

一遍遍抄写的词表、算式、还有被老师改过的错字。

这是人类最早的「学校作业」。

## 学的是什么

**写字。**

准确说，是学一种叫**楔形文字**的复杂书写系统——几百个符号，每个都有好几种写法。

要学好几年。

## 为什么值得学好几年

因为**会写字的人太少了**。

在那个时代，能读会写意味着：

- 可以记账、收税
- 可以管理仓库
- 可以替国王下命令

**文字是权力，识字的人是权力的执行者。**

## 学校长什么样

- 一群男孩（是的，主要是男孩）坐在泥板前。
- 老师示范，学生照着刻。
- 错了就刮掉重来。
- 抄写、背诵、再抄写。

**和今天很像，也很不一样**：那时没有「启发式教学」，因为目的不是培养思考，是培养**可靠的执行者**。

## 一个值得想一想的问题

我们今天送孩子上学，是在培养「会思考的人」，还是「能执行的人」？

这个问题的答案，决定了你怎样看待作业、考试和纪律。
