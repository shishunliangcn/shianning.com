# 一条河，怎么养出一个文明

🌊 古埃及在尼罗河边，古巴比伦在两河之间，古印度在印度河边，中国在黄河边。

为什么都在河边？

## 因为河边有饭吃

河水每年泛滥，把上游的泥沙带到下游，铺在两岸。

那层泥，是最肥的土。

不用施肥，撒下种子就有收成。有了多余的粮食，才有人可以不当农民——去当祭司、工匠、士兵、书记员。

**分工，是文明的第一步。**

## 因为洪水逼人合作

但河也会发疯。

尼罗河还算温和，每年固定涨落；两河的洪水来得没有规律，说来就来。

要挡住洪水、要挖渠灌溉，一家一户干不了，得几十个村子一起干。

**一起干，就需要有人安排、有人记账、有人强制。**

于是出现了最早的「国家」。

## 河流也会杀死文明

这一点不太常被提起。

长期灌溉会让土地盐碱化——水把地下的盐带到表层，庄稼越来越长不好。

两河流域的一些古城，就是这么荒掉的：不是被敌人灭的，是地被自己浇坏了。

## 所以呢

地理不是命运，但它划定了可能性。

- 有大河 → 能种粮 → 能养更多人 → 能分工 → 能出现复杂社会。
- 河太凶 → 治水成本高 → 更容易出现高度集权的组织。
- 地浇坏了 → 文明搬家或衰亡。

**「环境塑造人」这句话，在历史的尺度上看得最清楚。**
