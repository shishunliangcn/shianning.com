# 历史不是年份表

📅 「秦朝公元前 221 年统一六国。」

背下来了，考试也能写对。但一周后就忘了。

因为你记住的不是历史，是一串数字和名字的组合。

## 历史到底在讲什么

历史真正的题目只有一个：

> **人在什么处境下，会做出什么选择。**

公元前 221 年发生了什么，不重要。重要的是：为什么是秦国统一了六国，而不是楚国？为什么统一之后，那个制度只维持了十五年？

那些问题，今天还在发生。

## 三个反复出现的模式

**一、权力会自己长大**

一个原本用来办事的机构，时间久了会开始为自己办事。

秦的郡县制、罗马的元老院、公司里的中层——形式不同，逻辑一样：**权力倾向于扩张，直到遇到边界。**

**二、粮食决定很多事**

不是「英雄创造历史」，是「先有饭吃，才有力气创造历史」。

每一次大饥荒之后，几乎都跟着一次大动荡。这条规律比任何帝王的传记都稳。

**三、恐惧会找替罪羊**

社会一出问题，人们就想找一个「都是他们的错」的群体。

中世纪的黑死病、二十世纪的经济危机——每次都能看到同样的动作：先找一群人，再把问题推给他们。

**这一条，今天依然在发生。**

## 怎么读历史才有用

不要记「谁做了什么」，问三个问题：

1. **谁受益？** 这个决定，谁拿到了好处。
2. **谁承担代价？** 好处和代价，往往不是同一批人承担。
3. **如果是我，在那个处境里会怎么选？**

第三个问题最难，也最有用。它让你知道：**很多我们今天觉得理所当然的事，在当时并不是唯一的选择。**

## 一个提醒

「读史使人明智」这句话只对了一半。

读史也可能让人变得犬儒——「反正人性就这样，什么都改变不了」。

区别在于你怎么读：**如果只看到重复，会绝望；如果看到「每次都有人试图改变」，才有用。**
