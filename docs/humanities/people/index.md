# 👤 人物

> 知音馆 · 穿梭历史与人文

读传记最大的收获，不是「他多厉害」，而是「他在两难时怎么选」。
这门主题写人，也写那些没有留下名字的人。

## 会聊到的问题

- 天才真的是天生的吗？他们的日常是什么样的？
- 一个人如何改变一个领域，又付出什么代价？
- 历史书上没写的人，过着怎样的生活？
- 如果我们处在他们的位置，会做同样的选择吗？

## 学习方式

- **读多本传记**：同一个人的不同版本，差异本身就是史料。
- **关注失败**：成功故事的同质化最严重。
- **写一段对话**：假设你能问他一个问题，你会问什么？

## 准备

- 一本你真正想读的传记（不是别人推荐的「必读」）
- 一张人物关系图：他影响了谁，又被谁影响
