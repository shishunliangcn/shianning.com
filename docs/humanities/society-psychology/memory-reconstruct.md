# 你的记忆，每次回忆都在重写

🎞️ 你以为记忆像录像：发生过什么，就存着什么。

**其实更像拼图：每次回忆，都是重新拼一遍。**

## 为什么这么说

大脑不是把细节原样存起来，它存的是**要点和感觉**。

回忆的时候，大脑用这些要点，加上**你现在的知识、情绪、期待**，重新构造出一个「当时」。

**所以每次回忆，都是一次改写。**

## 一个经典现象

让一群人看同一段车祸视频，然后问：「车撞碎的时候，速度大概多少？」

换一个词问：「车碰到的时候……」

**仅仅换了一个动词，被试估计的速度就不一样。**

词语暗示，改变了他「记住」的画面。

## 记忆最会骗人的三种情况

**1. 情绪强烈的时候**

越激动，越容易记错细节，但**越确信自己记得对**。

**2. 反复讲述之后**

每讲一次，就改写一次。讲得越多，越偏离原样。

**3. 被别人「补充」之后**

别人说的细节，会被你吸收进自己的记忆里。

## 这有什么用

**对别人：**

证人的记忆不一定可靠——这不是说他在撒谎。

**对自己：**

- 重要的决定，**当时就写下来**，别只靠回忆。
- 和别人争论「当时到底谁说了什么」，往往争不出结果，因为双方都在重写。
- 你对童年的记忆，很多是「听家人讲的」+「照片里的」。

## 一个温和的结论

**记忆不可靠，但它也不是无用的。**

它帮你保留意义、提取教训。

**只是别把它当成法庭上的证据——包括你自己的。**
