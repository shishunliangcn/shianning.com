# 🧩 社会与心理

> 知音馆 · 穿梭历史与人文

人独处时是一种样子，进入群体又是另一种样子。
这门主题同时看「外面」的社会结构和「里面」的心理机制。

## 会聊到的问题

- 为什么人在人群中更容易做出格的事？
- 我们为什么会买其实不需要的东西？
- 偏见是怎么形成的，又怎么被打破？
- 「我」的性格是天生还是养成的？

## 学习方式

- **警惕直觉**：心理学里最反常识的结论，往往最有证据。
- **看研究怎么做**：样本、对照、重复，比结论更重要。
- **用来理解，不用来贴标签**：概念是工具，不是武器。

## 准备

- 一个观察日记：记下让你觉得「奇怪」的日常行为
- 一份愿意被推翻的自我认知
