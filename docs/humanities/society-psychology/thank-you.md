# 「谢谢」是什么意思？

🍎 阿姨递过来一块苹果。

妈妈接过去，说：「谢谢。」

宝宝看着，也想说，但没说出来。

## 这两个字在说什么？

它在说一句话：**我看见你为我做了一件事。**

不是礼貌，是看见。

阿姨把苹果洗干净、切开、递过来——这些动作都是她做的。说「谢谢」，就是告诉她：我知道你花了力气。

## 一起做：递东西

1. 妈妈把球递给宝宝：「给你。」
2. 宝宝接过去。妈妈等一等，不催。
3. 换过来：宝宝把球递给妈妈，妈妈说：「谢谢宝宝。」

一天玩五六次，不用说「你要说谢谢」，他听多了会自己冒出来。

## 给家长的话

- **不要逼**：2 岁的孩子不说「谢谢」很正常，逼出来的只是复读。
- **先自己说**：你对服务员、对家人说谢谢，他听到的比教的多。
- **说具体一点**：把「谢谢」换成「谢谢你把球捡起来」，他才知道这两个字对应的是哪件事。
