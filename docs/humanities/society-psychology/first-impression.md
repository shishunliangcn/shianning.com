# 第一印象为什么不可靠

👀 见到一个人的三秒内，你已经形成了判断：

「这人挺靠谱」「这人有点傲慢」「这人不好接近」。

**而你几乎没有任何证据。**

## 晕轮效应

心理学术语叫**晕轮效应**（halo effect）：

**一个突出的印象，会「晕染」到其他所有方面。**

- 长得好看 → 我们会顺带觉得他更聪明、更善良。
- 说话声音大 → 我们会觉得他更自信、更有能力。
- 一个人幽默 → 我们会觉得他更值得信任。

**但这些品质之间，本来没有必然联系。**

## 更麻烦的是：我们会自我实现

一旦你认定某人「不友好」，你就会：

- 少跟他说话
- 表情更冷
- 他感受到之后，也对你冷淡

**然后你心想：果然，我就说他不友好。**

你亲手验证了一个你自己制造的结论。

## 三个可以做的调整

**1. 把「感觉」和「事实」分开**

「我觉得他傲慢」——这是感觉。
「他刚才没回我消息」——这是事实。

**感觉不是证据。**

**2. 换情境再看一次**

同一个人，在会议上可能沉默，在饭桌上可能很健谈。

**一个场景里的表现，不足以定义一个人。**

**3. 给自己一个延迟**

第一次见面不做结论，只做记录。

**过三次接触再判断。**

## 反过来也用得上

别人对你的第一印象，同样不可靠。

**所以别太在意「第一次没表现好」——大多数人对人的印象，都会被后续修正。**
