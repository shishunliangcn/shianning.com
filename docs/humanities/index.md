# 📜 知音馆

> 穿梭历史与人文

历史不是年份的堆砌，哲学也不是绕口令。
这座展馆想做的事很简单：让过去的人重新开口说话，让你听见他们在争什么。

## 这座展馆有什么

| 主题 | 聊什么 |

## 怎么逛这座馆

1. **先读故事，再读结论**：抽象的道理放在具体处境里才看得懂。
2. **把观点当问题**：别急着同意或反对，先问「他为什么这么想」。
3. **和自己对照**：读懂古人的前提，是承认自己也有偏见。
