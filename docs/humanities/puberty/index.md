# 🌼 青春期与性教育

> 知音馆 · 穿梭历史与人文

性教育不是「一次严肃的谈话」，而是从小到大、随时可以提问的日常对话。
这个主题讲两件事：身体发生了什么，以及什么是边界。

## 会聊到的问题

- 身体什么时候开始变化？变化有快有慢正常吗？
- 月经、遗精、变声，该怎么和孩子说？
- 什么是「身体边界」？别人碰我哪里是不可以的？
- 网上看到不好的内容，怎么办？
- 喜欢一个人，是正常的吗？

## 三句话可以先立住

1. **身体是你自己的**，不舒服的触碰可以拒绝，也可以告诉大人。
2. **好奇是正常的**，问出来比偷偷查更安全。
3. **没有愚蠢的问题**，只有还没被好好回答的问题。

## 给家长

孩子问「我是从哪来的」，不是要一份生理学讲义，而是在确认：
这件事能不能和你聊。你的反应，比你的答案更重要。
