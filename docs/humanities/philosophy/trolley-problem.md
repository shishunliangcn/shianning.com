# 一辆失控的电车，和你的选择

🚋 一辆刹车失灵的电车，正冲向五个人。

你可以扳动道岔，让它转向另一条轨道——但那条轨道上有一个人。

**你扳不扳？**

大多数人会说：扳。死一个，总比死五个好。

## 换个版本

还是那辆车，还是五个人。

但这次你站在天桥上，旁边有一个很胖的人。把他推下去，就能挡住电车。

**你推不推？**

大多数人会说：不推。

## 问题来了

**两种情况，结果都是「死一个，救五个」。**

为什么一个可以，一个不行？

## 两种思路

**1. 只看结果**（功利主义）

哪个选择让总伤害最小，就选哪个。

按这个逻辑，推人也应该推。

**2. 看行为本身**（义务论）

有些事不能做，哪怕结果更好。

「把人当工具推下去」就是不能做的事。

## 这个实验的用处

它不是要你选出一个正确答案。

**它是让你发现：你其实同时相信两套规则，而且它们会打架。**

- 你说「生命不能用数量比较」——但你也支持「牺牲少数救多数」。
- 你说「不能主动伤害别人」——但你也觉得「见死不救」有问题。

## 一个诚实的结论

**道德不是一套能算出来的公式。**

它是一堆互相拉扯的原则，你得在具体情境里自己称重。

**哲学没法替你做决定，但它能让你知道自己在拿什么做决定。**
