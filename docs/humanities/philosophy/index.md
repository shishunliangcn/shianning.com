# 🕯️ 哲学

> 知音馆 · 穿梭历史与人文

哲学不是玄谈，是把人人都觉得理所当然的问题，重新认真问一遍：
什么是公平？我怎么知道我知道？人应该怎样活？

## 会聊到的问题

- 如果没人看见，做坏事还算错吗？
- 「我」是身体、记忆，还是别的什么？
- 自由和规则一定冲突吗？
- 一个论证怎样才算成立？

## 学习方式

- **把结论还原成问题**：先看他反对谁，再看他说了什么。
- **写下来**：哲学靠写作思考，不写就等于没想。
- **接受不确定**：好问题往往没有终局答案，只有更清楚的理解。
