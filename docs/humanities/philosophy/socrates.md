# 苏格拉底为什么甘愿赴死

公元前 399 年，雅典法庭以「不敬城邦之神」和「败坏青年」两项罪名，判处苏格拉底死刑。
他的朋友安排好了一切：船、路线、钱。他拒绝了，最终喝下毒堇汁。

大多数人的第一反应是：何必呢？

## 一场看起来很不公平的审判

苏格拉底没有请辩护律师，也没有痛哭求情。
他站在五百人的陪审团面前，做的却是继续追问别人：「你说你懂美德，那么美德是什么？」

这种提问方式得罪了太多人。他最终的「辩护」，是一段让陪审团更生气的演讲——
他自称是城邦的「牛虻」，职责就是不断叮咬这匹迟钝的马。

于是死刑判决以微弱多数通过。

## 他本可以逃

《克里同篇》记录了逃亡当晚的对话。
克里同劝他：你死了，朋友会被人耻笑没尽力，孩子也失去父亲。

苏格拉底的反问是：**逃走，是「正当」的吗？**

## 他给出的理由

他没有说「我要以身殉道」，而是给了三条理由：

1. **判决已经作出，逃避就是破坏法律**。他一生受法律保护，不能在对自己不利时才否认它。
2. **以错还错不是正义**。别人不义，不代表你也可以不义。
3. **死亡未必是坏事**。要么是归于虚无，要么是灵魂去往别处——两种都不值得恐惧。

你可以不同意每一条，但要承认：这是一个**可以被检验的论证**，而不是情绪。

## 两个至今还在争的问题

**第一，个人良知与法律冲突时，该怎么办？**
苏格拉底选择了服从，但同一座雅典后来又处死了主张「公民不服从」的另一种声音。
这个问题没有标准答案，只有一次次具体的选择。

**第二，哲学有什么用？**
它在当时没能救他的命。但它让两千四百年后的人仍在问：我此刻过的，是不是我想要的生活？

## 为什么今天还值得读

因为他的死法本身就是一次教学：
**说的和做的要一致**——如果一个人一生都在论证「美德即知识」，那么最后一刻就是他交卷的时候。

::: tip 读法建议
先读《申辩篇》，再读《克里同篇》，最后读《斐多篇》。
三篇连起来，就是「审判—逃亡—赴死」的完整过程。
:::
