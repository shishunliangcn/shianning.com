# 📈 经济与管理 · 大学殿堂

> 18 岁以上 · 学科概况

经济学教你「世界为什么这样运转」，管理学教你「在既有的约束下怎么把事情做成」。
前者是解释，后者是行动。

## 重点内容

- **微观经济**：供求、弹性、成本、市场结构与激励。
- **宏观经济**：GDP、通胀、利率、财政与货币政策。
- **组织与管理**：目标、分工、激励、沟通与决策。
- **财务常识**：复利、现值、风险与收益的基本关系。

## 学习建议

- 用经济学解释身边的小事：为什么奶茶店总开在一起。
- 学管理先看案例，再看理论，最后回到自己的团队或社团。
- 建立「机会成本」的思维习惯，做选择时会清醒很多。
