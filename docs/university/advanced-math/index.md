# 📐 高等数学 · 大学殿堂

> 18 岁以上 · 学科概况

大学数学的门槛不在计算，而在「定义」和「证明」。
先建立直观，再补严格性——两者缺一，学起来都会痛苦。

## 重点内容

- **微积分**：极限、导数、积分的几何意义，先想清楚「在描述什么」。
- **线性代数**：向量空间、矩阵、特征值，抓住「线性变换」这个核心。
- **级数与微分方程**：收敛性判断、一阶与二阶方程的解法。
- **证明方法**：反证、归纳、构造，学会写出完整的证明。

## 学习建议

- 每个定义都问一句「为什么这样定义，去掉条件会怎样」。
- 定理先看条件再看结论，条件往往就是解题的钥匙。
- 做题之后回看教材，把方法归到某一节的知识框架里。
