# 🔤 英语 · 大学殿堂

> 18 岁以上 · 学科概况

大学英语的目的是「用英语做事」：读文献、写论文、做报告。
四六级只是路标，真正要练的是学术场景下的读写与表达。

## 重点内容

- **学术阅读**：读懂论文结构，抓住研究问题与方法。
- **论文写作**：摘要、引言、方法、结果、讨论，各部分的常用句式。
- **考试准备**：四六级与雅思的题型差异和备考节奏。
- **学术演讲**：结构清晰、控制语速、应对提问。

## 学习建议

- 精读一篇本专业论文，比泛读十篇新闻更有价值。
- 写作从模仿开始：先抄句式，再换内容。
- 口语练习录音回听，重点改停顿和连接词。
