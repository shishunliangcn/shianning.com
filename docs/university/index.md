# 🎓 大学殿堂

> 18 岁以上 · 建立框架，学会自己找答案

大学之后没有人再替你划重点，学习的重心从「记住结论」转向「读懂论证」。
六门学科提供的是六种看世界的方式，而不是六份考题。

## 这个学段在做什么

- **从被动到主动**：先自己找资料、提问题，再来看这里的整理。
- **重论证轻结论**：知道结论怎么来的，比记住结论更重要。
- **跨界连接**：通识给视野，数学给严谨，计算给工具，经济给判断，心理给理解，规划给方向。

## 怎么陪着学

1. **先读原始材料**：教材和论文原文永远优先于二手总结。
2. **写下来才算懂**：能用自己的话讲清楚，才是真的理解了。
3. **建立笔记系统**：知识库本身就是这个学段最重要的产出。
