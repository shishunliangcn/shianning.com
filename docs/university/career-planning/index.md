# 🎯 职业与规划 · 大学殿堂

> 18 岁以上 · 学科概况

职业规划不是「选一个专业就定终身」，而是持续做三件事：
认识自己、认识行业、小步试错。

## 重点内容

- **自我认知**：兴趣、能力、价值观，用具体经历而不是形容词来描述。
- **行业地图**：主要行业与岗位的职责、门槛、成长路径。
- **信息获取**：招聘网站、行业报告、校友与实习渠道。
- **求职实务**：简历、面试、作品集与实习复盘。

## 学习建议

- 用「做过什么—结果如何」写简历，而不是罗列课程。
- 大二前至少完成一次实习或项目，真实体验胜过想象。
- 每年更新一次职业规划，允许自己改变主意。
