# 🎵 音乐 · 大学殿堂

> 18 岁以上 · 学科概况

到这里，音乐不再是「听个响」，而是可以分析、可以评论、可以放进历史脉络里理解的对象。
学习方式是「听—读—写」循环：听作品、读总谱与史料、写分析。

## 重点内容

- **西方音乐史**：从中世纪到二十世纪，各时期的技法与美学。
- **作品分析**：曲式、和声、配器，能说清一段音乐「怎么搭起来的」。
- **民族音乐**：中国各地乐种与中国传统音乐的美学特征。
- **乐评写作**：描述、分析、评价三段式，避免只写感受。

## 学习建议

- 同一部作品听三个版本，比较速度、音色与处理差异。
- 分析从曲式入手，先画出结构图，再谈细节。
- 写乐评时把「我感到」换成「因为……所以……」。
