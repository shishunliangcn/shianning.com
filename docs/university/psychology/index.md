# 🧠 心理学 · 大学殿堂

> 18 岁以上 · 学科概况

心理学不是「猜别人在想什么」，而是用可验证的方法研究行为与心智。
先理解自己，再理解他人，是这门课最实用的部分。

## 重点内容

- **认知心理**：注意、记忆、学习与决策中的系统性偏差。
- **发展与人格**：生命周期各阶段的特点，人格差异从哪来。
- **社会心理**：从众、说服、群体行为与人际吸引。
- **研究方法**：实验设计、相关与因果、常见统计误读。

## 学习建议

- 读到「某某效应」时，先问：样本是谁、效应多大、能否重复。
- 把概念用在自己身上做观察记录，比背定义更有用。
- 区分「通俗心理学」和「有证据的心理学」，前者只当消遣。
