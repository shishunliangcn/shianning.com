# 📖 语文 · 大学殿堂

> 18 岁以上 · 学科概况

大学语文的重点从「读懂文章」转向「写出站得住的论述」。
阅读的对象变成论文、评论和经典文本，写作的目标是让人信服，而不是让人感动。

## 重点内容

- **学术阅读**：快速判断一篇文献的问题、方法、结论和局限。
- **论证训练**：区分事实与观点，识别常见逻辑谬误。
- **学术写作**：摘要、文献综述、论证结构、规范引注。
- **经典细读**：选少量文本反复读，读出新旧理解的差异。

## 学习建议

- 读论文先看摘要和结论，再决定要不要通读。
- 每读完一篇写 200 字摘要，逼自己提炼而不是复制。
- 写作先搭论证骨架，再补材料，避免堆砌。
