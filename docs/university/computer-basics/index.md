# 💻 计算机基础 · 大学殿堂

> 18 岁以上 · 学科概况

计算机基础的目标不是「学会一门语言」，而是理解这台机器如何执行你的想法，
并把它变成可以重复使用的工具。

## 重点内容

- **编程入门**：变量、控制流、函数、数据结构，选一门语言学透。
- **计算机组成**：二进制、内存、CPU 与操作系统的分工。
- **数据结构与算法**：数组、链表、树、排序与查找的复杂度。
- **工具链**：命令行、版本控制（Git）、调试与文档查阅。

## 学习建议

- 先写能跑的小程序，再追求优雅，别一上来就啃大部头。
- 每学一个数据结构，手写一遍实现，比看十遍图有用。
- 学会读官方文档和报错信息，这是最保值的技能。
