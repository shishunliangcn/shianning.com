# 📖 语文 · 小学课堂

> 6–12 岁 · 学科概况

小学语文的四件事：认字写字、朗读背诵、读懂文章、写出通顺的句子。
顺序不能乱——字词不过关，阅读和写作都会卡住。

## 重点内容

- **识字与写字**：每天 5–8 个新字，重点看笔顺和结构，不要只抄不记。
- **朗读与背诵**：出声读，读到不打结为止；古诗和短段落先背下来。
- **阅读理解**：学会在文中找依据，答案要能指出「从哪句话看出来」。
- **写作起步**：从看图写话到写清一件事，先求完整，再求生动。

## 学习建议

- 生字本按「易错笔画」而非按课文顺序整理，复习效率更高。
- 每周精读一篇短文，比泛读十篇更有用。
- 写作先列提纲：谁、什么时候、做了什么、结果怎样。
