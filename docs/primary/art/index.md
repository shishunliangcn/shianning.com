# 🎨 艺术审美 · 小学课堂

> 6–12 岁 · 学科概况

小学的艺术课是「敢」的阶段：敢画、敢唱、敢上台。
技法可以慢慢练，但表达的信心一旦丢掉，很难再捡回来。

## 重点内容

- **美术**：线条、色彩、构图，尝试水彩、蜡笔、拼贴等不同材料。
- **音乐**：识谱入门、整齐歌唱、竖笛或口风琴。
- **手工与设计**：折纸、剪纸、简单的立体造型。
- **欣赏与表达**：能说出「这幅画哪里打动我」。

## 学习建议

- 每周留出一段「随便画」的时间，不设主题、不打分。
- 学一件小乐器，坚持一学期比换来换去强。
- 带孩子看展、听音乐会，审美是见出来的。
