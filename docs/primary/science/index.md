# 🔬 科学探索 · 小学课堂

> 6–12 岁 · 学科概况

小学科学的关键不是记住结论，而是走完一次完整的探究：
提出问题、做出猜想、动手验证、记录结果、解释现象。

## 重点内容

- **观察与记录**：用文字、表格、简图记录实验现象。
- **常见实验**：溶解、浮沉、电路、光的传播、简单机械。
- **生命与地球**：植物生长、动物习性、天气与岩石。
- **科学思维**：区分「看到的事实」和「我的猜想」。

## 学习建议

- 每周留一次「家庭小实验」，材料从厨房里找。
- 实验前先写下猜想，做完再对照，这是科学思维的起点。
- 记录本比实验本身更重要，坚持写才会形成习惯。
