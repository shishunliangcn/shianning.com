# 🎵 音乐 · 小学课堂

> 6–12 岁 · 学科概况

小学音乐开始进入「看得懂谱、唱得整齐」的阶段。
识谱是工具，歌唱是日常，乐器是延伸——三者互相支撑。

## 重点内容

- **识谱入门**：五线谱的音名与唱名，简谱的数字与高低音点。
- **整齐歌唱**：跟准伴奏、统一换气、控制音量，学会听别人的声音。
- **简单器乐**：竖笛、口风琴或口琴，选一样坚持一学期。
- **合唱基础**：分声部、听和声，理解「一起唱」和「唱得好」的区别。

## 学习建议

- 每天吹/唱十分钟，比周末练一小时有效。
- 用熟悉的歌练识谱，比枯燥的谱例更容易坚持。
- 录下自己的演奏，对照原曲找差距。
