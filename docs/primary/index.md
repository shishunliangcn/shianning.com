# 🎒 小学课堂

> 6–12 岁 · 打好底子，让基础扎实可依赖

小学阶段拼的不是聪明，是基本功和习惯：读得懂题、算得准、写得清、敢开口。
语文、数学、英语三线并进，音乐用来给学习留一点呼吸的空间。

## 这个学段在做什么

- **把字写对、把题读懂**：审题和书写习惯比刷题量更重要。
- **建立知识链条**：每个新知识都要能挂到已有的知识上，而不是孤立记忆。
- **练习检验**：算完要验算，写完要通读，这是能带走一辈子的能力。

## 学科入口

| 学科 | 这个阶段学什么 |
| --- | --- |
| [📖 语文](/primary/chinese/) | 识字写字、朗读背诵、阅读理解、写作起步 |
| [🔢 数学](/primary/math/) | 计算能力、应用题审题、几何初步、单位换算 |
| [🔤 英语](/primary/english/) | 自然拼读、高频词、基础句型、听读训练 |
| [🎵 音乐](/primary/music/) | 识谱入门、整齐歌唱、竖笛与合唱 |

## 怎么陪着学

1. **先复习再写作业**：花五分钟回顾当天课堂内容，写作业会快很多。
2. **错题比新题值钱**：同一类错误连续出现三次，就该停下来专门练。
3. **每天读一点**：语文和英语都靠持续输入，十分钟朗读胜过周末突击。
