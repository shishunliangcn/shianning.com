# 🔤 英语 · 小学课堂

> 6–12 岁 · 学科概况

小学英语的关键期在「听」和「说」，不在背语法。
先把自然拼读的规则打通，看到单词能读出来，英语学习会顺很多。

## 重点内容

- **自然拼读**：掌握 26 个字母及常见组合的发音，做到见词能读。
- **高频词**：先拿下最常用的 200 个词，阅读就能读懂大半。
- **基础句型**：自我介绍、问路、购物、时间表达，场景化记忆。
- **听读训练**：每天听十分钟，跟着音频模仿语调。

## 学习建议

- 单词不要单独背，放进句子里记，用的时候才想得起来。
- 朗读时录音再回听，孩子自己就能听出问题。
- 遇到生词先猜再查，别一遇到就停下来查字典。
