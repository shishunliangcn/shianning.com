# 💻 信息技术 · 小学课堂

> 6–12 岁 · 学科概况

信息技术的目标不是「会用某个软件」，而是建立三样东西：
操作的基本功、编程的思维方式、以及网络上的安全意识。

## 重点内容

- **基本操作**：打字指法、文件与文件夹管理、截图与搜索。
- **图形化编程**：Scratch 一类的积木编程，理解顺序、循环、条件。
- **信息素养**：判断信息真假、尊重版权、不泄露个人信息。
- **数字创作**：用工具做一张海报、一段动画、一份简单报告。

## 学习建议

- 打字从正确指法开始，宁可慢，不要养成二指禅。
- 编程先从「让角色动起来」入手，兴趣比语法重要。
- 和孩子一起讨论网上的信息是否可信，比装过滤软件更根本。
