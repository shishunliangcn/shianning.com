# 🏛️ 人文素养 · 小学课堂

> 6–12 岁 · 学科概况

人文素养在小学阶段的任务，是先建起两根轴：时间轴和空间轴。
知道事情有先后、地方有远近，历史和地理就都有了落脚点。

## 重点内容

- **历史故事**：从神话、成语典故到重大事件，先有兴趣再谈年代。
- **地理常识**：看地图、认方向、知道家乡在中国的哪里。
- **传统文化**：节气、节日、礼仪、经典诵读。
- **社会常识**：钱从哪里来、公共设施谁维护、规则如何产生。

## 学习建议

- 用一条家庭时间轴（出生、搬家、上学）理解「过去和现在」。
- 出行时让孩子看地图找路，空间感是走出来的。
- 节日不只过节，也讲讲它的来历。
